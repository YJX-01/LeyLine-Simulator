# team-core-v1 反应扩展

旧 combat-core-v1 保持阶段3行为。真实内容使用 team-core-v1；新增风、岩、雷伤害与扩散、结晶、超载、超导、感电、水雷共存和基础冻结/碎冰。仍为单目标，不实现扩散对其他目标的传播，也不模拟敌人受击位移、盾元素量和草反应。

剧变伤害不暴击、不吃角色攻击/伤害加成或敌人防御；使用触发者等级表、实时精通和对应元素抗性。增幅反应仍使用该技能快照策略。反应系数按2026-11-05核对的KQM资料采用超载2.75、感电2、超导1.5、扩散0.6、碎冰3，明确不同于旧Python的历史系数。结晶仅记录反应，不自动假设角色拾取护盾。[反应公式与机制](https://library.keqingmains.com/combat-mechanics/elemental-effects/transformative-reactions)

水雷分别保留元素量，感电首次触发与后续每秒消耗双方0.4U，归属最近有效施加者；不足半秒的尾段不追加一次伤害。火作用于水雷共存可同时蒸发与超载。风岩消耗0.5倍触发量，不能成为附着。水冰冻结保留底层剩余元素，冻结量按2×min(原附着,触发量)计算并非线性衰减；钝击/岩可碎冰。[元素量依据](https://library.keqingmains.com/combat-mechanics/elemental-effects/elemental-gauge-theory)

伤害日志将剧变列为独立 source=reaction，直接命中的 damage 不包含它；总伤害和角色贡献包含全部反应伤害。自然感电跳不作为友方直接攻击触发协同技能。草反应、复杂冻结反复共存、场地自附着及多目标传播不在首批角色验收场景中使用。
