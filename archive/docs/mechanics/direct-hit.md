# 单次直接伤害：旧规则迁移

此阶段迁移依据是仓库 `archive/python/src/core/rules/dnode.py` 的 RES、DEF 函数及 `damage.py` 的基础乘区，不宣称已经验证当前游戏版本。测试输入为人工构造，没有已支持的角色。

伤害 = 攻击力 × 技能倍率 × (1 + 伤害加成) × 暴击系数 × 防御系数 × 抗性系数。

- 期望暴击系数 = 1 + 暴击率 × 暴击伤害；必暴击 = 1 + 暴击伤害；不暴击 = 1。
- 防御系数 = (100 + 角色等级) / ((100 + 角色等级) + (100 + 敌人等级) × (1 - 减防) × (1 - 无视防御))。
- 有效抗性 r < 0：1 - r/2；0 ≤ r < 0.75：1 - r；r ≥ 0.75：1/(1 + 4r)。有效抗性由调用者提供，尚未实现减抗来源管理。
- 比例均以小数输入，无界面百分数隐式转换。敌人配置可省略，保持旧公式验证输入兼容，此时防御和抗性系数为 1。

手工基准：攻击力1000、倍率2、加成0.5、暴击率0.5、暴伤1，基础期望伤害4500；双方90级、无减防/无视防御时系数0.5，抗性0.1时系数0.9，最终2025。减防0.5和无视防御0.5组合，防御系数为0.8。

暂不包含反应、额外基础伤害、快照、属性增益、敌人特殊减伤或角色技能。输入限制为当前验证台的支持范围，并非游戏合法属性范围的完整定义。
