- 四包边界、共同角色/账号/项目/文件/协议契约；按内聚单元拆分schema。
- 140个角色使用共同第2版JSON，包含介绍、成长、技能参数、被动、命座及能力声明；内置、自定义、导入导出、角色培养与计算共用。136个有源文本，4个明确未收录；不扩大机制支持。
- 同一参数同时驱动技能说明和命中倍率；结构化天赋加级替代独立文字匹配规则。自定义试配保持未核验身份。
- 当前引擎收敛为属性/伤害、效果依赖图、时间轴；历史内核、旧表、旧导出及相关工具整组归档。
- 账号、项目、队伍、角色配置、定义库的旧格式先校验/预览/确认，再写独立v2副本；保留原文件、v1存储、数值、ID与穿戴。缺失文本与稀有度不猜测。
- tests集中、素材统一根assets；桌面/server归应用，工具分类，docs仅现行Markdown，历史文档归档，规范有唯一入口。
- 精度审计覆盖148174个值；新五星主词条取固定原表，125处差异保留记录，旧保存快照不自动替换。

## 实施取舍

- 当前属性解析和直接伤害共约240行，保持在`engine/src/attributes/build.ts`这一内聚单元；效果图和时间轴各自独立。方案中的damage/diagnostics职责有对应实现，没有为了目录树另建空模块。
- 仓库未采用本地字体文件，因此资源入口没有空的fonts目录。
- 新检出先执行`pnpm data:build`，再执行独立的typecheck/test及只读检查；dev/build会准备生成物，CI也在检查前显式生成。运行分块和资源索引保持不提交。
- 浏览器回归跟随当前已认可交互，更新旧选择器、显式展柜导入选项、命名、手动添加入口、排序和多选筛选断言。跨浏览器传递原文件字节；长任务的总流程时限独立于产品性能预算。

## 回归中修复的行为

- 莫娜套装核对按原始扫描词条计算指纹，不把本地推断的强化次数加入物品身份；同时识别历史核对指纹。用原始458件库存的旧格式衍生项验证修复后再次导入全部为重复项，数值、强化记录及ID保持。
- 跳至主要内容链接显式加入键盘Tab顺序，修复WebKit跳过首个链接的问题；不改动已认可的页面布局和字号。
- v1缺少的命座加级、文本和稀有度保持未知；迁移提示说明缺口，不用当前目录静默补齐旧快照。

## 明确限度

当前支持琴、凯亚、行秋零命战技四段及已核验静态效果。其余内容收录不等于机制已实现。没有实录完整战斗轴，不能宣称整轴性能或游戏伤害观测验收。配色v1后续反馈与本次结构验证分别记录；远端CI未运行，Windows本地检查不等于已证明Linux/Safari设备行为。
