## 已交付范围

固定本地快照目录含 126 个角色、256 件武器、63 套圣遗物。保留基础值、成长曲线、突破增量及采用的天赋倍率；目录数量代表固定来源版本，不代表当前游戏最新内容。运行、普通生成、测试及构建无需 `.references` 或网络。

首批可验算琴点按战技、凯亚战技、行秋战技两段，限零命；行秋突破4水伤20%纳入静态规则。支持无锋剑、银剑、西风剑、祭礼剑、旅行剑、黎明神剑、腐殖之剑的已核验伤害属性；低星武器按真实等级上限校验。产球、重置、治疗不推演额外事件。静态套装效果按快照标注，未核验4件效果及其他机制明确提示部分支持，拒绝输出完整伤害。

真实面板由引擎求值，显示属性来源、倍率、防御、抗性、暴击与增伤乘区。等级、突破、天赋、武器、精炼、生命比例、圣遗物及目标条件可通过 UI 修改。未知暴击/反应显示待确认；不支持命座/装备不伪装完整计算。行秋逐段生成记录，时间由用户指定，不推算命中间隔。

账号可保存真实角色和实际装备；轴持有采用的完整数值快照。复制后账号、候选和内置库互不回写，旧轴不会随库更新。实物按账号和实例标识限制唯一占用，混合来源的候选保留每件实物的账号命名空间。旧 P2 手动攻击输入、定义库与文件格式继续兼容。

莫娜第一版 JSON 可预览再导入五星库存，支持部位、套装、主副词条和比例单位；保留原始主值及来源身份。相同属性的不同实物不合并，重复文件不重复新增；同来源 ID 内容变化必须明确勾选更新，并保留角色归属。没有 ID 时采用内容与出现次数，无法据此推断不同来源文件里的实物身份。导入不自动装备。样本是依照固定上游类型构造的格式验证文件，见 [fixture 说明](../../tests/tests/fixtures/mona/README.md)。

异步加载绑定原项目/角色，切换后的旧操作不会写进新对象。保存状态按 JSON 内容比较，不因字段顺序变化误报未保存。真实输入继续通过新轴 Worker 求值，支持既有撤销、重做、恢复及迟到结果隔离；CLI 使用同一内核。

## 用户逐步验收

1. 双击 `artifacts/desktop/Start-LeyLine.cmd` 打开最新本地桌面包。网页可运行 `pnpm dev`，操作相同。
2. 在“项目”新建空轴，进入“队伍”，选择琴，初始武器西风剑，点击“添加真实角色到当前轴”。保持默认等级90/突破6、零命、战技9、武器90/突破6、精炼1、生命比例1，不装备圣遗物。
3. 点击“添加技能全部独立命中”。默认明确不暴击、无反应；目标90级、各抗性0.1、减防与无视防御0。应看到下表琴结果。展开属性来源及乘区核对。
4. 分别新建空轴，将角色改为凯亚、行秋，重复操作。行秋应有两条独立伤害记录，时间轴中可逐段编辑时间和同刻顺序。
5. 将战技天赋9改8、换武器或调整抗性，确认重新计算。把所选命中暴击/反应改未知，应显示待确认。选命座1或未核验武器，应看到部分支持说明。
6. 保存轴，修改天赋，再打开保存文件：输入和数值恢复，状态应为无未保存修改。撤销/重做应往返恢复；刷新后用“恢复上次编辑”检查恢复输入后重新求值。
7. 先保存需要保留的账号资料，再在“角色”新建账号。到“圣遗物”选择 `tests/tests/fixtures/mona/mona-v1.json`，预览应新增3件五星；确认后同属性两朵花仍是独立实物。再次预览应新增0件、已存在3件。
8. 在“角色”创建账号角色，点击“设置账号真实角色”，装备第一朵导入的花。默认琴攻击应为 **749.402464**；复制真实配装到一个空轴，添加战技后伤害应为 **1674.0152**。账号改天赋或装备不会改变已复制轴。若保留默认普通伤害模板而非空轴，总值为 **6074.0152**。
9. 分别保存/新建/重开账号与轴，确认库存、实际装备、候选和结果各自恢复。定义库仍能独立保存复用。不要使用清理输出命令删除准备保留的桌面包与验收文件。
