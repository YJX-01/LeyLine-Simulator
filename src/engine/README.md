# engine

当前属性与直接伤害在attributes，效果依赖求值在effects，时间轴校验及求值入口在timeline。只依赖schema，并只计算调用者提供的快照。退休模拟器不从包入口导出。公式及边界见[直接伤害](../../docs/calculation.md#伤害计算)。

| 入口 | 维护职责 |
| --- | --- |
| resolveStaticBuild | 成长、装备与静态修饰 |
| resolveBuild | 通过共同依赖图求属性 |
| evaluateDamage | 独立单点上下文与共同伤害公式 |
| evaluateTimeline | 当前项目校验、状态及事件顺序求值 |
| compareTimelineLoadouts | 同轴完整Build替换，各候选独立装配 |
| compileCalculation | 检查模板数据闭包、精确版本、单位、依赖循环与展开预算，返回不可变程序 |
| evaluateFormula | 运行明确纯公式输出，返回known/unknown/invalid、按输出关联的诊断和逐节点追踪 |
| evaluateBoundFormula | 将角色/目标属性、参数、事实、效果与捕获按需绑定到相同纯公式解释器 |
| calculationEffectInstanceId | 用所有者、精确定义和触发事件构造适用事实引用的实例身份 |
| evaluateDamageQuery | 求明确技能命中或既有事件的输出，只累计该事件列出的伤害occurrence |
| selectCalculationValue | 按eventId+outputId或明确事件合计读取结果；缺失、删除或失效不自动改选 |
| checkInventoryFeasibility | 独立检查明确账号中的库存重复占用，不修改数学输出或装备引用 |
| compileStructuredCharacter | 校验v3角色的闭包、属性面板、命中输出、参数单位与全部绑定 |
| compileCharacterActions / evaluateStateMachine | 校验精确角色动作闭包，按显式事件运行状态与独立时效，返回事件阶段快照 |
| collectCalculationRoots / collectCalculationClosure | 从明确注册表收集精确依赖，输出独立JSON；工具与浏览器共用 |
| prepareStructuredBuilds | 校验v3内容及配装，装配每名队员的原始属性、一次天赋加级和条件效果 |

| evaluateAggregate | 逐贡献者求值、按声明依据排序和加权；在每个独立/联合概率状态内重排后求精确期望 |

combatRules复用项目表达式，支持减法、min/max、比较、分支、精炼参数、天赋参数和战斗状态读取。项目事件在装配时关联，正式规则以自身及接收者、动作/命中技能选择器表达关系。单位相加与比较须相容，转换先归一化来源单位，再乘目标单位系数。

效果实例身份保留所有者、来源实体及修订、规则与触发事件。常驻效果显式permanent，在合法最大查询时刻3600000毫秒仍常驻；触发效果使用左闭右开区间和before/after。修订中的禁用、固定值及失效引用按现有语义执行，完整五类修订的接入状态登记于[计算资料](../../tools/data/README.md#计算支持与验证资料)。

calculation 中的纯公式编译不读取游戏目录或网络；调用者提供公式、表和来源的完整快照。相同完整身份可合并相同内容，冲突或缺修订直接拒绝。攻击、生命、防御和精通通过显式scale-to-damage转换；相加要求同单位，乘法至少一侧无量纲。

静态校验覆盖全部节点、属性和效果绑定，select和嵌套调用的运行输入按需读取。每次运行重新建立缓存与追踪，输入对象和编译快照独立；0乘未知仍为未知。运行限制为100000次访问、128层深度和100000条追踪，公式、属性、效果实例筛选与嵌套绑定共享预算，达到预算返回明确诊断。当前新接口尚未替换现有Build/效果/时间轴求值入口。

上下文读取明确区分owner、recipient和contributor。效果未解锁、命中筛选不符、区间已结束或适用事实明确为false时，跳过效果值的依赖；资格未知则相关结果保持partial。端口输入由效果合并独占，不能重复手工绑定。只检查声明目标的效果，不穿透纯公式调用修改内部节点。

捕获按槽声明的技能、属性及阶段校验，来源事件必须满足所有者和时间约束。每项绑定独立选择捕获或动态读取，当前状态覆盖不会带到其他来源事件。属性和效果依赖循环返回cycle；规则可显式excludeCurrentEffect，运行时不自动消除循环。

事件来源图检查循环与已知的未来引用。同刻同序的不同事件保持顺序未知；效果起止与同组刷新需要该顺序时返回待补事实。状态区间使用左闭右开语义，按对象/字段索引读取；显式null覆盖已知区间，重复覆盖和多位队员同时站场拒绝。显式事件状态机已接入，自动派生事件仍待实现。

source-event属性和事实读取共用时间/阶段校验：未来来源拒绝，同刻同序且先后未知时保持partial；当前before不能读取自身after。hit与event中的公式输出共同核对已声明的队员、技能、命中、类别、目标和反应身份，无单一所有者的聚合保留原归属语义。

聚合只读取请求明确列出的贡献者及各自输入；固定值、独立随机变量与完整联合概率表分别执行。相关性由同一变量的多项绑定或联合表明确给定，不由角色身份猜测。精确状态预算为256；0/1概率只展开可达分支，超限不回退为“各人期望后排序”。逐人运行、概率展开与排序共享总访问/追踪预算，来源规则未定义的额外名次不会补0。

并列指标只在实际贡献相同或对应名次权重相同时使用稳定ID排序。固定指标并列、实际贡献和权重均不同时返回partial/unsupported-semantics，保留组件追踪，排名与小计不填猜测值。

事件输出按共同computation区分公式和聚合，actorId可空的多人聚合保留参与队员及概率状态中的逐人排名。独立反应的元素/来源描述不继承普通攻击类别；公式未声明的防御、普通增伤等输入不会读取。只求已明确提供的输出，不自动生成延迟伤害或依据sourceEventIds递归累计来源伤害；没有独立伤害的资源事件可明确提供空输出列表。

单个输出和事件合计均可选择。其他输出未知时，已知单个输出可独立读取，事件合计保持unknown；没有“已知部分合计”回退。多个输出复用已校验上下文，共享总访问、深度和追踪预算。

evaluateBoundAggregate接收每名贡献者的BoundFormula、读取帧及明确资格；每个概率状态重新通过共同属性/效果求值，再交由aggregate.ts的同一排序和加权执行。独立变量的概率可绑定角色属性，只有明确crit-rate按暴击规则截断，普通概率越界拒绝；关联事实由共享变量或完整联合表表达。固定排序另给rankFrame，不能复用候选换装前的排名。捕获、缺事实、反应目标与事件语义共用现有校验；概率读取和所有贡献者共享预算，追踪包含概率依赖。

prepareStructuredBuilds第二参数可显式提供当前反应数据闭包，和配装拥有的数据一同校验、去重及拒绝冲突，不查询目录。createStructuredCombatContext产生实际配装输入；事件computation的bound-aggregate分支接入该入口并核对反应、目标及所有贡献者。实际查询范围记录于[计算支持与验证资料](../../tools/data/README.md#计算支持与验证资料)。

feasibility报告库存占用。账号与物品身份都明确时可判断跨队员冲突，已脱离库存或缺账号的内容保持unknown。项目装配、同步查询和Worker使用同一结构化求值入口，计算器按双方存档分别复算数值与库存占用。

v3装配只读取所给快照，不调用旧静态修饰求值器。成长、突破、武器副属性及圣遗物先成为原始输入；比例与固定值分别提供给属性图，静态/动态加成仅由效果图施加一次。实例/部位重复、非法培养、坏引用和同一完整实体身份的内容冲突在求值前拒绝，跨队员共享实物交由独立feasibility检查。

参数有效等级为基础等级加已解锁命座奖励一次，缺少对应等级保持未知。ratio与scalar保持比例，energy/stamina保留单位；seconds按十进制毫秒转换，无法精确表示为安全整数毫秒的项保持未知，不舍入。参数读取的追踪带原参数表来源。

角色编译递归校验自身拥有的效果predicate/value、属性基数与命中绑定中的技能参数和原单位，诊断指向实际绑定位置；属性依赖遍历受深度预算限制。队友/受益者参数按实际角色在运行上下文核对，缺参数为missing-dependency，合法参数缺对应等级值才返回未知。

高层命中入口使用角色自己的稳定命中和输出定义，检查本人、队友、武器和已激活套装的相关覆盖。未表达机制或超出证书命座范围时保留数学组件追踪，最终输出为unknown/partial并追加coverage节点。所给事件与命中事实冲突时拒绝；独立捕获记录不承载伤害输出。此处的覆盖只适用于明确输出，不证明自动动作、能量或队伍整体可执行性。

四/五星圣遗物均按Build自身artifactMain[rarity][stat][level]读取；两条求值路径使用同一星级边界，检查套装rarities与slots。旧单表缺失会被严格契约拒绝；范围上限不声明已观测到强化过程。

## 固定TS算法与JSON配置

calculation/templates.ts按已注册模板及精确revision装配计算；templates-common.ts固定普通伤害、防御、抗性、暴击和面板算法，templates-reactions.ts固定反应算法与通用常数，aggregate.ts固定排序、并列与概率枚举执行。JSON只描述缩放项、倍率绑定、阈值、上限、效果与模板引用，不接受任意运算节点、签名、端口或脚本。

formula-ir.ts与template-builder.ts属于私有执行层，保留单位检查、惰性读取、共享预算和逐步追踪；它们不属于文档契约。describeCalculationTemplate提供独立的签名、常数及依赖描述，不导出可执行图。collectCalculationRoots只导出模板配置及实际可达数据。

CalculationBundle 的 schemaVersion 与 runtimeVersion 均使用当前软件版本（0.1.0），声明fixed-templates-v1；模板revision目前只接受1。新增算法或不兼容变化先升级TS模板及明确版本，未知版本拒绝，既有JSON不能定义新算法。

固定模板还提供有单位的线性转换、数量/枚举条件与布尔组合。组合条件在已知项足以决定结果时隔离无关未知，非法值和预算失败仍拒绝。直接反应模板可显式启用技能基数倍率；该倍率只作用于基数，专属固定加值仍在反应和精通增益之后，普通增伤与防御不进入星伤分支。

## 显式动作与状态

compileCharacterActions接收动作、精确角色快照及可选的显式数据依赖；共同编译器核对技能/命中/输出、参数单位、来源和状态规则。维护来源可引用公共库；生成和交换快照携带所需闭包，离线重开只需动作文件、所选角色及匹配运行时。动作文件不复制伤害参数或替换角色，删除/修订后的引用直接失效。

evaluateStateMachine使用event-state-v1，算法固定在state-machine.ts。每次运行独立持有初始值、资源、定时状态及逐层过期记录；先过期、再检查守卫并按明确priority执行before/after转换。set/add/consume/clear/unknown是受控操作，资源不足拒绝，缺初始值、容量依据、消耗或过期记录时保留未知。同刻同序不以ID排序；所有公式读取和状态转换共享访问、深度和追踪预算。

结果stateFrames按对象、事件和阶段保存。共同属性读取优先采用当前显式覆盖、该事件阶段快照、状态区间和静态事实；动作后的状态不泄漏到动作前或其他来源时刻。已有相同对象/事件/阶段/字段的快照拒绝覆盖。只有显式列出的事件参与本次运行；未知动作帧不补零，不自动扩展轮次、命中或风翎。

薇斯纳的来源边界见[动作采用记录](../../tools/data/sources/calculation-hits/vesna-actions.json)，源条件检查在tests/unit/engine/calculation/state-machine.test.ts；这些检查验证软件语义与明确条件，不表示已有玩家动作录制或完整可执行性。
