# 统一资源入口

`game/`保存游戏图标，`ui/`保存应用装饰，`sources/`保存采集配置及矢量原件；`manifest.json`记录实际文件、来源、变换与别名，不保存逐文件SHA-256。所有维护文件均在本目录。

`pnpm data:build`验证并复制到`.cache/public/assets/`，生成web运行索引；Vite只分发该构建副本。`pnpm assets:check`核对当前定义引用覆盖、原件、尺寸、别名和预算。采集是显式维护动作，普通构建不联网；生成索引和分发副本不能手工编辑。许可范围见[资源说明](../docs/references/ui-assets.md)。

当前2076个本地图标覆盖154份角色定义的1424个头像、技能和实际命座引用；覆盖在生成时实时验证。缓存revision由实际文件自动计算，只进入生成索引。
