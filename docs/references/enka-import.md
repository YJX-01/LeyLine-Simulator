实际输入使用官方文档直接提供的公开示例 [UID 618285856](https://enka.network/api/uid/618285856/)，不是用户自己的账号。取得的原始响应保存在忽略的 `.references/enka/official-example.json`，SHA-256 `e41b52d6abe70e2d571ac1da7505a09e209391c01dfbce7c8bdbe99fd971ea45`。本轮另做实际网页与桌面网络请求；网页实收时间 `2026-11-06T15:03:57.648Z`，响应 SHA-256 `9252b9a42f2d57c636d46d633222e1e2b1e451ea38f3c5fdd62438852596d026`，4 位角色为安柏、班尼特、甘雨、行秋。TTL 会变化，原始响应和自动化账号保存文件不是可冒充的游戏导出。未上传或提交用户莫娜文件。

## 操作与边界

角色页右侧 **展柜导入 → 输入 UID → 查询 → 预览勾选 → 确认**。只读取公开展柜，不要求登录凭据，也不能读取未展示角色或完整背包。新增/补全默认勾选；已有完整角色默认不选，明确勾选才更新培养和武器。重复导入保留角色身份与本地穿戴；确认时核对账号与所选角色快照，预览后发生修改则拒绝覆盖。导入后定位到所选角色，清除可能遮住结果的搜索/筛选。

角色等级、突破、命座、三类天赋、武器等级/突破/精炼按响应保留，不采用“满级”默认值替代观察值。生命比例来自 `fightPropMap[1010]/[2000]`，不会把不满生命值的展柜角色改成满生命；这仍然只是展柜缓存条件，不等同于实战轴条件。原有手动添加的满级默认设定保持。

**展柜配装默认只保存快照。** `showcase:*` 是观察位置的本地快照键，不是游戏实物 ID。默认“仅保存展柜”不增加 `account.artifacts`，不改变本地 `equipment`。角色详情以“本地／展柜”切换来源；仅有展柜时默认展示快照。

2026-11-08 用户明确允许在预览中选择“同时导入本地库”，默认关闭。只有明确选择后，才对套装、部位、星级、强化等级、主词条和值、副词条及其顺序逐项精确匹配；不近似、不四舍五入、不忽略顺序。完全一致时复用本地实物 ID 与原穿戴关系；不一致则新增本地 ID，保留展柜来源。此为用户授权的内容匹配，不能据此声称已证明游戏内实物身份。确认导入不自动装备，也不自动创建组合；预览后库存变化会拒绝覆盖。

角色展柜页的“保存组合”先打开未保存草稿；缺少对应本地物品时，在编辑器左上角点击“保存”后才确认“入库并保存组合”；取消或放弃草稿均不写库存或组合。已存在相同组合则打开已有项，不自动改写。本地角色页可“应用组合”，只修改草稿；转移、卸下需要确认，仍由角色“保存”提交。组合编辑不改变任何角色当前穿戴。

当前导入范围受既有固定目录与 RealBuild 契约约束：培养等级 1–90、五星圣遗物、明确的武器/套装/天赋映射。未核验的旅行者冰元素/奇偶元素身份、缺少 SkillOrder 的新条目、缺字段或不支持星级会逐项列出原因，不猜测。拥有新角色资料不表示其技能或套装全部效果已可计算。用户莫娜库存和该公开 UID 属于不同来源，本轮没有拿它们拼接“同账号”的完整配装验收。

## 请求与实现

- 桌面通过固定主机的 IPC 方法查询，校验渲染来源与 9–10 位数字 UID，保持现有 CSP。网页开发服务及本地 `serve-dist` 提供同源 `/api/enka/:uid`；子路径按应用 base 前缀处理。纯静态托管需另提供同源通道，否则明确提示使用桌面/本地预览，不宣称所有静态站点已能跨域直连。
- 使用自定义 User-Agent，按服务 TTL 缓存、合并相同 UID 的进行中请求，缓存上限 16 个 UID；单次响应上限 2 MiB，上游超时 15 秒。只对用户明确查询的 UID 发请求，不枚举账号。
- 取消/关闭会中止网页请求或丢弃桌面的迟到结果；查询与预览不会写入账号。400/404/424/429/服务异常有就近反馈。不会因网络失败改变本地库存。
- 网络原始契约位于 schema 的公开子路径 `@leyline/schema/enka`；UI 领域模块只依赖纯映射与工作区公开导出，不引入状态/平台模块。两个社区名称/Enka ID 映射都置于 `src/web/src/domain/data/`。

验证：真实响应的独立字段比对检查培养、武器、生命比例和装备等级；验证确认前无写入、重复导入及迟到快照拒绝覆盖、快照不进入实物库存。网页实际请求与桌面实际请求都通过预览/确认；桌面用独立空账号验证公开示例，另一个任务才验证用户 458 件莫娜库存，来源不混合。没有游戏伤害观测或完整轴材料，本轮不声称数值或整轴验收完成。
