## 采用与证据边界

- 先对应实体ID、形态、游戏版本、天赋等级与解锁条件。网页可能更新既有角色规则，不能因角色同名就与固定来源混用；差异先登记，再明确采用版本。
- 页面值、隐藏参数与机制说明分别核对。保留来源精度，不从显示百分比反推更高精度，不将未注明含义的隐藏值直接写入规则。
- 如需采用新数据，显式保存来源依据并制备候选，审查后才更新正式JSON。普通生成维持离线，不依赖这些站点在线访问。
- 多站资料相同不自动构成独立验证；可能来自相同原表。独立公式计算、实际资料功能检查及游戏观测继续按[证据规范](../standards/evidence.md)分别记账。
- 此次访问只完成入口调查，没有完成五站完整许可、批量抓取或全角色机制核验；不据此复制网站实现或采用全部内容。动态渲染和访问失败的页面在实际审查相应条目时继续查找，不要求用户现在补全站点资料。
