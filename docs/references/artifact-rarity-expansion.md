# P5非五星圣遗物来源与消费者核对

2026-11-11。落实用户已批准的非五星培养、手动录入和外部导入范围。本轮只核对已有资料与源码，未采用新表、未放宽生产契约、未运行游戏数值或实际导入验收。范围及工作包见[P5计划](../planning/p5-character-usability.md)。

上述原表属于固定LunaGC提交b0501c5d89767ead5f647869a2412521447f7682，不能从更多行或更多小数推断可用等级和精度。源level与显示强化等级的映射需要逐星级核验。现有来源可先制备候选，实际采用前需补齐合法范围及版本相容性依据。

GenshinTools副词条求解和计分主要面向四、五星，部分入口将其它稀有度归一为五星或跳过低星校验；这些回退不能照搬。本地kqm-tcl的装备说明和evidence可用于后续具体套装机制核验，本轮没有据其断言完整升级规则已取得。

手动编辑、星级/强化筛选、组合、角色配置、项目复制和文件保存均通过这些契约消费资料，实施时沿直接消费者核对。有效条数的白值基准及组合冻结政策保持，档位折算若需调整必须明确新旧口径，不能在扩大稀有度时顺带改变已有分母。

## 具体实施顺序

1. 补齐来源关联：固定完整升级、物品与词条池配置或可独立核验的等价依据，逐星级记录可用等级、初始条数、升级事件和合法部件。与已有参数原表逐字段核对；不从原表长度猜上限。
2. 制备待审候选：保留rarityList、分星级主词条、适用副词条及规则。列出相对当前五星数据的差异，普通构建仍离线，不覆盖正式JSON。
3. 落实共同契约与数值读取：同时更新内容、实物、快照、面板和生成投影；明确必要版本变更，不恢复旧格式迁移，不修改已有用户文件。
4. 接通录入和导入：Mona、Enka及手动编辑复用同一合法性规则；同步星级匹配、内容指纹、已记录强化历史和推断历史，检查取消/失败及合并行为。
5. 核验和交付：来源数值逐项比较、合法/非法边界检查、五星回归、非五星真实原件检查、文件往返及受影响浏览器流程；缺原件明确跳过并保留未完成结论。

## 当前停止线

首轮确认了一至五星数据入口和主要消费者，未完成全部星级的合法升级/词条池映射。正式采用与放宽校验必须等来源依据核验；可以继续资料调查和契约草案，不先让未经核验的组合进入计算。材料缺口不改变用户已批准的全目录目标。
