# 迁移状态

## 旧项目初步盘点

- UI：PyQt5 生成的窗口，入口 src/main.py。
- 模拟：优先队列、事件与动作系统；Simulation、NumericController、CreationSpace 和 Trigger 存在单例状态，不能直接迁移为共享服务状态。
- 指令：角色.命令@时间，部分附加符号控制暴击；旧 Operation 使用 exec 查找控制器，新实现改为显式注册。
- 规则：伤害、治疗、元素、附着冷却、增益；存在实现不等于验证完整或符合当前游戏规则。
- 内容：雷电将军、行秋、胡桃、阿贝多、琴存在技能模块；完整性尚未验证。docs 下 JSON 和 src/data/README.md 仅作为盘点线索。
- 可视化：Matplotlib 图表与日志，新界面将消费结构化结果。

## 当前进度

- 已落地：实施计划、workspace、输入校验、单次攻击、动作调度、限时伤害增益、Worker 调用、动作编辑表和事件日志。
- 当前支持 formula-sandbox-v1、legacy-direct-hit-v1、synthetic-rotation-v1 与 repo-jean-tap-v1；琴点按战技部分支持，其余角色尚未支持。面板为人工构造，角色配置只对仓库数据负责。
- 已验证：TypeScript/Vue 类型检查、46 个单元测试、生产构建；本机 Edge 的5个浏览器用例覆盖单次攻击、动作增益边界、非法配置恢复、取消、Worker 加载异常恢复和琴技能流程。CI 配置使用 Chromium。
- 未完成：旧 Python 环境复现、外部数据来源及版本核实、角色完整实现、其他战斗机制、持久化、图表与性能基线。
