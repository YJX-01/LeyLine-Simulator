# 命中输入与附加基础缩放

层数和资源附加倍率复用现有多属性基数及属性依赖图。分项绑定不解除完整角色的未实现依赖，边界见[内容支持](content-support.md)。

## 共同契约

技能可声明inputs，每项包含唯一ID、非负有限上下界、是否必须为整数及固定来源；constellationLimits可按已解锁的最高命座门槛替换上限，每条修订保留来源。命中的additionalScaling项可用count引用本技能的输入；主缩放和不带count的附加项沿用原公式。参数仍引用同一技能已有的等级数组，不复制或四舍五入倍率。

单次请求damage.inputs明确提供输入值或null；未提供与null均为未知，不能按零计算，也不读取队员inputs、其它命中、最近施放或描述文本。命中输入是对当前分项所需事实的明确断言，不是额外攻击次数，也不是自动推演的战斗状态。声明上限不证明某条轴能达到该值。

基础伤害为各项「属性 × 等级参数 × 输入值」之和；不带count的项其因子为1。已知零层的项贡献为零，不读取该项专属属性；未知层数使该项未知。选中命中未使用的已声明输入不参与依赖，提供的非法值仍拒绝。未声明的输入、越界、非法小数和非有限数值在共同schema或求值入口拒绝。

evaluateHitBase消费同一属性reader，直接求值和时间轴共同调用；捕获属性仍依照命中声明处理。结果scaling保留参数、属性、倍率及count的输入ID和值。层数增量先进入基础伤害，再进入增伤、暴击、防御、抗性和适用反应乘区；不能伪装成百分比damageBonus或拆出另一次命中。

项目文件、内置／自定义定义及Worker消费同一契约。旧快照不自动填零或从新目录替换。addSkillHit遵循当前查询覆盖；计算器可输入技能参数，但输入字段存在不解除未实现的角色、被动、命座或装备限制。

## 来源与核验

范围依据固定genshin-db提交8e5badd60b5d894284ccc927a56c9683529d2592的对应talents文本和参数；加算、分段和动态读取依据固定KQM TCL提交7fb4e7d54d38e9e7549f778ac9bdcfc626c646d5的四份角色机制页。事实摘要保存于tools/data/sources/kqm-tcl对应提交目录的count-scaling-facts.json，未复制或执行上游实现。网页北斗和优菈正文可读，绫人/雷电本次网页没有可读正文，采用已核对的固定本地文件，不从空页面推断规则。

候选先输出到artifacts/content-candidates/count-scaling-2026-11-14，逐项检查角色、参数、命中类别和范围后采用；绫人二命上限单独在count-scaling-limits-2026-11-14审阅，并对照同提交的constellations原文确定为五层。原有167243项来源数值零差异；该审计不自动覆盖新范围及机制，后者另做来源和公式检查。

单元核验使用来源数值推导的合法零命单点配置，覆盖北斗三档、绫人前三段及水影排除、零层不读生命、雷电小数愿力与拆分攻击、优菈初始/爆炸区分、缺输入、越界和错误引用。显式提供独立属性上下文可以核对基数公式，结果仍保留未支持诊断；候选属性上下文检查不冒充完整依赖图换装通过。图检查保留输入和未知属性，文件往返及实际Worker检查保留count并区分已知/未知，未伪造玩家配装、伤害观测或战斗序列。

阈值、非线性、累计或跨角色附加基数不能直接套用本契约。自动积攒、施放关联、持续区间及完整操作可执行性尚未实现。
