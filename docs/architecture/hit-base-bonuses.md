# 命中附加基础伤害与来源适用事实

装备或队友提供的基础加值复用[内容规则依赖图](content-rules.md)和共同伤害公式。

## 计算位置与属性读取

baseDamage仍表示本技能的多属性/层数基数；baseDamageBonus表示来自已选中效果的附加基础伤害，使用damage单位。最终公式为「技能基数 + 效果基础加值 + 激化等反应基础加值」，再乘受益命中的增伤、暴击、防御、抗性和适用的增幅反应。基础加值不是百分比damageBonus，也不是另一条独立伤害，不重复统计命中。

baseDamageBonus属于命中数量，不加入StatKey、面板或培养修饰。来源效果通过现有节点读取所有者属性，受益角色提供本次命中的类别、元素及乘区；单位转换、循环、覆盖组、来源身份和预算沿现有依赖图执行。直接接口的完整reader需提供该数量，无加值时明确返回0；普通内部查询没有此类效果时以0为基础。

命中原有snapshot只控制声明的角色属性，新增基础加值按当前上下文读取，不随受益技能的面板捕获一起冻结。来源效果如果自身声明source捕获，仍使用该效果自己的明确来源；不将受益命中的状态或捕获时点冒充来源事实。结果保留baseDamageBonus、属性/效果依赖和原始技能缩放项。

## 来源实例的命中适用事实

效果可声明requiresApplication，表示还有未被自动推导的次数、冷却等适用事实。对应damage.effectApplications逐命中引用稳定instanceId，active为true、false或null；缺失与null均为未知，不当作默认可用或零贡献。false排除此项并避免读取其专属来源属性。事实不从其它命中、相似来源、最近一次施放或队员inputs继承。

引用必须属于实际装配的来源、允许的接收者、命中类型和有效区间。有触发事件时必须先于命中；同刻依赖需要不同的明确order。重复事实、错误对象、未来或过期来源、错误命中类别等拒绝。来源被删除、换装或版本变化时保留stale-revision待核对，不把事实附到新的相似实例。

覆盖组先选择有效实例，再读取所选实例的适用事实；新实例为false不会使已被替换的旧实例重新生效。事实不是人工效果修订：禁用仍排除来源，固定值只替代贡献而不证明它适用，错误单位仍拒绝。setDamageEffectApplication与携带事实的addSkillHit共同校验完整候选；无效编辑不改变当前项目。没有新增界面控件，当前通过文件/接口及Worker使用。

内容规则及共用项目定义可携带明确support。选中尚未支持的规则时保持部分结果，固定贡献也不解除这项限制；仅在未用分支中的规则不污染无关输出。此前已审查规则省略此新增字段时沿用原语义。所有新增字段均为当前契约的可选字段，不转换旧文件、不改写原快照或补写旧命中事实。
