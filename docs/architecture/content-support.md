# 内容收录与计算支持

当前目录包含154个角色定义、256把武器、63套圣遗物。角色JSON均已收录适用的介绍、技能/被动/命座文本、成长与等级参数；每个实体使用共同schema。基础空/荧和奇偶的文本已补齐，奇偶男女各七种元素形态分别保存；基础形态不虚构元素技能，奇偶没有命座。收录不等于全机制可计算。

2026-11-14[阶段复核及返修计划](../planning/p5-character-usability.md)明确区分分项核验、正式完整查询与用户操作交付。本轮R1新增有限的查询覆盖证明及用户明确要求的侧栏计算器，具体如下；未获证明的角色／非零命查询仍沿用保守阻断。原桌面release未更新，不能从源码或开发浏览器能力推断旧包可用。

本轮新增正式完整路径：北斗C0捉浪单次命中在明确0/1/2档位、合法基础双手剑及敌人条件下得到有限伤害；凯亚C0—C3霜袭在核验已解锁命座作用范围后复用天赋加级。正式Build、共同图、文件、Worker及独立候选重算共用同一路径。角色整体支持标记未扩大；北斗缺档位、相关未审装备、凯亚C1普攻缺目标冰附着规则、C4及更高命座等仍阻断。详见[覆盖契约](query-damage-coverage.md)。

学徒笔记、新手长枪、猎弓、铁尖枪、佣兵重剑、口袋魔导书、历练的猎弓和训练大剑已逐件核验固定源数值及无被动语义，并采用显式passive声明。仅这8件新增支持，不能把缺少效果字段的其它武器解释为无被动。全部256武器继续在范围内，低星暂缓仅针对圣遗物实物。

独立计算器可手动设置角色／配装，显式读取本地或展柜，复制现有轴，输入已实现命中条件并查看伤害分项；固定基准后换装对照、保存计算文件与重开复算不改账号或原轴。没有完整Build的本地角色也可选，保留穿戴实物并在计算副本补培养与武器，不用展柜替代本地缺项；补全后可直接计算，无须先点应用。旧内置快照可经“检查当前内容”审阅后显式替换计算副本，自定义定义和比较基准不自动更新。既有时间轴记录详情新增控件仍只提交[具体评审稿](../design/p5-hit-conditions-review.md)，未实施。

R2本批新增凯亚C0—C1冰棱的独立捕获完整查询：明确命中时刻、来源技能的独立属性捕获时刻及读取阶段，经正式Build、图、文件、Worker和候选换装重算。不生成施放或其它命中，捕获点不触发宗室四件等动作效果；无来源或阶段仍未知，C2及以上爆发和C1普攻仍阻断。独立捕获时刻只表示输入断言，没有采用游戏捕获延迟，也不证明操作可执行。次数／冷却、贡献级动态与捕获分类、行秋波次、完整来源适用事实编辑及四星实物仍未收口。

R3首批新增诺艾尔C0—C3护心铠初始防御缩放岩伤、辛焱C0—C3热情拂扫初始攻击缩放火伤、雷泽C0战技点按／长按雷伤，以及芭芭拉C0—C1普攻／重击／下落8类单次水伤。四份定义revision3至4，原数值、角色和技能支持标记不变；来源、已解锁被动／命座范围及查询证明逐项核验，使用同一正式图、文件、Worker和独立候选。诺艾尔／辛焱C3复用技能加级；诺艾尔防御缩放不会因仅更换基础攻击武器而增加。辛焱脉冲、雷泽C1拾取增伤、芭芭拉C2水伤及各自未审主要路径继续阻断，不把这批有限路径当作四位整角色完成。

原有直接伤害支持琴、凯亚、行秋零命战技的四个命中参数绑定，以及这三位角色和基础空、荧零命未附魔的物理普通、重击和下落，共51项普攻族单次命中类型绑定；沿用已核验的静态装备效果及行秋突破水伤。命中类型不是一次施放的命中次数，动作不展开伤害序列。基础形态的支持不外推至元素形态。培养展示与伤害求值共用命座天赋加级读取；本轮仅为凯亚C0—C3战技增加查询证明，不代表其它非零命完整伤害支持。

伤害基数已可声明攻击力、生命、防御、精通及多项相加缩放，每项使用同一依赖图读取属性，按单次命中的元素和普通/重击/下落/战技/爆发类别处理。结果保留缩放项和基数；未知项不按零计算。只有实际读取的条件属性影响本次伤害，例如非暴击不依赖黎明神剑的生命条件暴击率。结构错误及未支持内容仍阻止完整结果。

2026-11-14此前接入[命中输入与附加缩放](hit-count-scaling.md)：技能声明有来源的输入范围，命中明确提供层数或资源，绫人浪闪、雷电愿力、优菈光降能量和北斗反击档位共17项复用既有基数公式。允许雷电小数愿力，缺输入不按零；零层不读取该项专属属性。原批次只交付文件和Worker输入与缩放追踪，没有界面控件。R1在此基础上仅贯通上文北斗C0 E，并在独立计算器提供数值输入；其它三位的完整属性／技能规则仍未核验，相关图依赖和完整结果仍保持未知。四位整体支持标记保持false，不能由分项公式外推整角色可用。

同日接入[装备/队友基础加值](hit-base-bonuses.md)：baseDamageBonus以伤害单位进入原命中基数，再使用受益者乘区。辰砂之纺锤R1至R5已核验明确适用事实下的当前防御加值，并贯通保存/Worker；缺少冷却等适用事实保持未知，不自动推导1.5秒间隔和0.1秒清除。云堇飞云旗阵Q基础防御项已绑定，次数消耗、hitlag延长、四突破及完整命座未接入，规则和角色仍为未支持。规则显式未支持不会被固定值修订解除。未扩大角色整体支持名单，界面未新增效果事实控件。

当前全部154份定义已进入[伤害绑定索引](../planning/p5-inventory-characters.md)，454个技能中444个共2013项基数绑定，另10个明确没有独立伤害，不以强化比例或治疗量伪造命中；其中10个技能、58项已标记支持。每份定义均有普攻族基数，战技/爆发同时核对多属性缩放和强化攻击类别，部分特殊/转换/反应攻击仍未绑定，具体例外见[P5实施记录](../planning/p5-implementation.md)。阿贝多、夜兰、纳西妲、那维莱特、胡桃及其它角色的条件、被动、命座和动态规则尚未贯通，整体未支持状态保持。索引、参数绑定和基础分项核验均不能作为全角色伤害贯通的完成证明。

新增琴零命爆发初始伤害，以及按[明确来源捕获](hit-attribute-capture.md)计算的琴领域出入、凯亚冰棱单次伤害。缺来源或阶段保持部分结果，按当前或来源时刻分别读取所需属性，候选重算捕获值；反应精通不随之冻结。独立计算器已支持明确捕获点与来源选择，既有时间轴新增控件仍待审；角色整体支持名单没有增加，游戏捕获延迟、完整增益分类及其它角色捕获仍待实现。

通用时间轴支持条件、区间效果、属性依赖/转换、捕获、来源修订、历史累计和计数，受深度和访问预算约束。旧模拟器的自动反应、能量、循环与历史角色脚本已退休，其旧能力不计入当前支持矩阵。

## 已批准的后续范围

2026-11-11，用户确认[P5全角色基础可用计划](../planning/p5-character-usability.md)：当前正式目录全部角色的主要攻击、核心机制、辅助职能及影响基础使用的被动、命座与反应，以及当前正式目录全部武器、套装的主要战斗效果须分批接入，并完成基础同轴配装比较。一支队伍只用于早期贯通，不能代替全目录完成。必要概率能力按角色需求在P5支持，深入概率分析后置。

为支持全部套装，用户另已确认P5包含非五星实物的培养、手动录入和外部导入。当前实物契约仍仅支持五星；实际套装星级集合、强化及主副词条来源将在实施中逐项核验。

2026-11-13用户将三星及以下实物暂缓，当前扩展范围为四星并保留五星；对应低星套装的实物配装验收单列暂缓，正式目录不删除，四星尚未因此成为已支持。实际战斗与换装对照待伤害计算可用后由用户提供，当前继续来源核对与独立计算。

以上全目录目标仍未完成；已实施的状态基础按本页具体范围登记。后续仅在实际规则和分层核验落地后更新支持范围；资料完整、台账登记或计划批准均不构成机制支持证据。
