# 内容收录与计算支持

正式目录包含154份角色／形态、256把武器、63套圣遗物。目录收录、技能参数、命中绑定和整体支持标记分别表达不同事实，不能互相替代。实际计算同时校验配装、查询覆盖、规则、装备和必要条件，未知项不按零补齐。

## 公共求值能力

[内容规则](content-rules.md)、[战斗状态](combat-state.md)、[反应](hit-reactions.md)、[捕获](hit-attribute-capture.md)、[命中输入](hit-count-scaling.md)和[基础加值](hit-base-bonuses.md)共用既有依赖图与伤害公式。文件、直接查询和Worker复用同一契约；每份候选重新装配来源和属性，不回写账号或原轴。

当前命中反应包括蒸发、融化、超激化和蔓激化；独立剧变、月反应和自动附着推演未实现。绫人浪闪、雷电愿力、优菈光降能量虽有分项绑定，仍缺完整角色依赖。云堇只有基础防御组件，次数消耗、四突破和完整命座未收口；辰砂加值要求明确适用事实，不自动推导触发、冷却和清除。

已核验的内容规则包含部分生命转攻击、指定被动，以及宗室两件爆发增伤和明确爆发动作后的四件攻击加成；单条规则成立不解除其角色或装备其它未实现依赖。

学徒笔记、新手长枪、猎弓、铁尖枪、佣兵重剑、口袋魔导书、历练的猎弓、训练大剑有逐件核验的无被动声明，合法最高70级／突破4／精炼1。其它武器缺少效果字段不能推断为无被动。圣遗物实物契约目前只接受五星；四星尚未实施，三星及以下实物暂缓。

## 用户入口与快照

独立计算器支持手动配装、显式读取本地或展柜、复制当前轴、输入已实现命中条件、独立捕获点及同轴候选比较，保存后经Worker重算。缺Build的本地角色保留实物穿戴，在计算副本补全；不借展柜填成本地事实。旧内置内容仅在明确审阅采用后更新计算副本，自定义定义和比较基准不自动替换。

现有时间轴未提供全部条件的编辑入口。独立捕获不触发施放效果，不生成动作或伤害；记录完整性、初始状态、贡献级动态／捕获分类、次数／冷却、完整修订和全目录主要机制仍有缺口。

已保存配装使用自身内容快照，源码提交和网页构建不代表已更新桌面包。来源审查、独立公式、真实资料功能检查及游戏观测按[证据规范](../standards/evidence.md)分开记录；当前没有完整实录队伍战斗轴或全面游戏伤害观测结论。产品目标见[需求与边界](../planning/product-direction.md)，不以目标扩大现有支持。
