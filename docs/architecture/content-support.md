# 内容收录与计算支持

当前目录包含154个角色定义、256把武器、63套圣遗物。角色JSON均已收录适用的介绍、技能/被动/命座文本、成长与等级参数；每个实体使用共同schema。基础空/荧和奇偶的文本已补齐，奇偶男女各七种元素形态分别保存；基础形态不虚构元素技能，奇偶没有命座。收录不等于全机制可计算。

直接伤害已支持琴、凯亚、行秋零命战技的四个命中参数绑定、已核验的静态装备效果及行秋突破水伤。培养和卡片使用结构化命座天赋加级展示；这不解除引擎对未核验命座完整伤害的限制。其他角色可保存、培养、显示与导出，复杂机制继续显示诊断，不静默按零或默认成立。

通用时间轴支持条件、区间效果、属性依赖/转换、捕获、来源修订、历史累计和计数，受深度和访问预算约束。旧模拟器的自动反应、能量、循环与历史角色脚本已退休，其旧能力不计入当前支持矩阵。

已保存数值来自项目/账号快照，不随目录更新。真实库存和公开展柜分别验证；没有实录全队战斗轴，因此不宣称完整游戏观测或整轴性能验收。后续内容、优化、概率与视频顺序见[产品路线](../planning/implementation-roadmap.md)。
