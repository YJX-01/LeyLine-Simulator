# 内容支持矩阵

“旧代码存在”与“新引擎支持”分别记录；新支持项均需注明来源和限制。

| 内容 | 旧资源 | 新引擎 | 验证边界 |
| --- | --- | --- | --- |
| 琴点按 E | Python技能、倍率表、动作表 | 部分支持 | 天赋1—10、直接伤害、动作锁、冷却；仓库数据配置 |
| 琴其他技能/命座/产球 | 存在模块 | 未支持 | 不允许通过任意技能字符串调用 |
| 雷电将军 | 存在模块 | 未支持 | 未审计 |
| 行秋 | 存在模块 | 未支持 | 未审计 |
| 胡桃 | 存在模块 | 未支持 | 未审计 |
| 阿贝多 | 存在模块 | 未支持 | 未审计 |
| 武器与圣遗物效果 | 部分模块及旧清单 | 未支持 | 手动基础属性不等同装备效果 |
| 基础攻击属性 | 旧属性系统 | 部分支持 | 基础攻击、攻击加成、固定攻击、暴击和伤害加成；不含等级成长 |

第一项的详细差异及来源见 `../mechanics/jean-tap.md`。所有角色当前游戏版本一致性仍待核实。
