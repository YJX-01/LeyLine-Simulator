# 阶段 3 验收清单

目标：交付可供阶段4角色内容复用的战斗机制内核，而非只增加新的独立公式页面。真实角色/武器/套装覆盖留在阶段4。

## 本阶段规则范围

- 单目标，1—4个手动面板角色，显式技能定义和结构化指令。
- 属性增益、直接伤害增益、独立叠加与同组替换刷新；半开区间。
- 动态/施放时面板快照；直接伤害增益、敌人状态不进入快照。
- 施放锁、技能冷却、能量条件、切人；失败不消耗资源或刷新冷却。
- 粒子/晶球、同异色/无色、前后台与充能、固定回复、溢出和消耗。
- 周期与协同召唤物，持续时间、同槽替换、后台归属及协同冷却。
- 标准2.5秒/3次附着ICD、无ICD；按施加者和附着标签隔离。
- 单一火/水/冰附着，1/2/4U、衰减、同色刷新、正反蒸发和融化。冻结、共存附着、剧变/草反应明确不支持，不静默估算。
- 期望/随机/强制暴击模式，显式随机种子，日志上限和任务预算。

## 验收门槛

- [x] 每项机制有独立人工可核算用例，覆盖开始、到期和同刻顺序。
- [x] 综合场景同一次运行覆盖切人、能量、召唤物、快照、增益和增幅反应。
- [x] 重复运行及不同场景交错运行结果稳定，随机模式可复现。
- [x] 错误输入/不支持反应/日志和事件预算超限明确失败。
- [x] 浏览器通过 Worker 执行综合场景，展示伤害、能量、反应和日志。
- [x] 配置编辑、取消、异常恢复通过浏览器测试。
- [x] 类型检查、全部单元测试、浏览器测试、生产构建通过。
- [x] 机制依据、范围、已知偏差与后续工作已记录；本地提交，不 push。
