# 单次伤害查询覆盖与候选复算

正式内容、属性和伤害使用共同定义及同一依赖图。覆盖证明表达已审查的查询边界，不是全角色支持标记，也不是界面中的独立公式。

## 覆盖证明

CharacterDefinition可携带damageCoverage，明确角色revision、skillId、命中索引、最高命座、固定来源，以及base、全部被动和已解锁命座的逐分支结论。irrelevant表示不修饰本次伤害，explicit-input表示相关机制由本次显式输入表达，talent-level表示复用共同天赋加级。不得从描述关键词或绑定数推导证明。

共同findDamageCoverage要求版本、技能、命中和命座范围匹配，且审阅分支完整。只有匹配查询可越过角色整体及非零命粗粒度守卫；装备、相关未支持规则、结构错误及必要条件仍须校验。无查询的完整面板保留原守卫，队友来源读取不能借用受益者的证明。缓存区分技能和命中，防止不同查询互相污染。

证明和来源随内置／自定义定义、Build、文件、导出及Worker保留。复制为自定义或编辑倍率会清除证明；derivedFrom不授予内置证明。JSON作者仍负责版本及来源审查，证明不是签名或防篡改凭据。实际有限路径见[支持范围](content-support.md)。

## 内容快照

读取旧文件不自动从目录补入证明或规则。“检查当前内容”制备角色、武器、套装、主词条表和反应规则的副本，列出变更，经明确采用才替换试配队员。培养、实物词条和装备选择保留，不回写账号／原轴；自定义角色拒绝替换，比较时须先结束对照。旧效果引用继续按原身份校验，不自动换绑。

武器passive.kind=none必须有逐件来源，且不能同时携带修饰或战斗规则；字段缺失不表示无被动。一／二星基础武器的非法精炼仍拒绝。

## 同轴候选与Worker

engine公开compareTimelineLoadouts，领域层及axis.worker调用同一入口。候选为轴内同一角色的完整Build替换，可更换本角色或队友；各候选独立重建规则、属性、捕获与伤害，不调用账号store，不改原项目，不生成攻击序列。缺队员、不同身份及重复候选／替换拒绝。

结果包含原方案、逐候选结果、目标及逐命中差值、Build变化字段和效果来源增删。任一侧未知则差值为null；旧instanceId修订和适用事实保留原引用，来源变化后失效仍待核对。

AxisRequest的candidates和AxisResponse的comparison为可选字段；单项目请求仍返回result。候选失败返回invalid与错误，任务编号保留。编辑清除旧结果，取消终止Worker，过期响应不采用。

计算器文件schemaVersion=1、kind=damage-calculator，最大8MiB，携带当前项目、可选基准及查看位置。比较锁定记录、条件、敌人、定义、状态区间、修订和目标，只替换配装；重开重新求值，不以保存结果为真值。伤害差值不证明动作、能量、攻速或整轴可执行性。
