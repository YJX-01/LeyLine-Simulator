# 单次伤害查询覆盖与候选复算

2026-11-14，R1。正式内容、面板及伤害仍使用共同定义和同一依赖图，不由界面另算伤害。用户操作入口为本轮明确授权的侧栏“计算器”；既有时间轴条件增量见[待审方案](../design/p5-hit-conditions-review.md)。

## 覆盖证明

CharacterDefinition可携带可选damageCoverage，每份证明明确角色revision、skillId、命中索引、最高命座、固定来源，以及base、全部被动和已解锁命座的逐分支结论。irrelevant表示已审且不修饰本次伤害，explicit-input表示相关机制已经由本次显式输入表达，talent-level表示复用共同天赋加级。枚举值不是计算脚本，不根据中文文本推导支持。

findDamageCoverage由schema导出，engine和web命中写入复用。角色revision、技能、命中、命座范围必须匹配；缺base、缺任何被动或已解锁命座的审阅条目时，不成立。装备、自身／队友内容规则及结构、属性和条件的检查不在证明中豁免。带未支持规则的相关依赖继续阻断；缺档位、暴击、反应、敌人或捕获等事实仍保持未知。

resolveStaticBuild仅在传入已证明的本角色伤害查询时绕过角色整体标记和非零命粗粒度守卫。无查询的完整面板继续沿用守卫；图内其它队员的来源属性读取不能借用受益者的证明。属性缓存包含技能及命中，避免同一队员某条已证明查询污染另一条未审路径。技能整体false也只在相同证明成立时允许本次命中；没有扩大角色、技能或命座的整体支持标记。

R1／R2三份证明：北斗revision5、C0捉浪命中0，已确认0/1/2反击档位；凯亚revision6、C0—C3霜袭命中0，以及C0—C1冰棱命中0。北斗A4限后续普攻／重击，凯亚C1限目标冰附着时的普攻／重击、C2限爆发延时；均不修饰本批E。凯亚C3的三级加成由talentLevelBonus读取，不改基础天赋存值。冰棱须显式来源捕获，C1普攻条件不影响冰棱；C2以上爆发继续阻断，其它攻击／命座不由此开放。

R3接续增加四份证明，当前共七份：诺艾尔revision4、C0—C3 E初始命中0；辛焱revision4、C0—C3 E初始命中0；雷泽revision4、C0 E命中0／1；芭芭拉revision4、C0—C1普攻族命中0至7。诺艾尔E为防御缩放，Q转攻击不修饰本次伤害；辛焱的物理增伤、普攻攻速和Q物理暴击不修饰E火伤；雷泽充能／雷之印不作为E伤害层数；芭芭拉C1能量回复不修饰普攻族。相关未实现的雷泽C1、芭芭拉C2仍阻断。来源与排除范围逐项保存在采用候选及全目录台账中，未按整体支持标记外推。

## 快照和消费者

共同角色版本仍为2，新增可选字段只补充分支证明，不改变既有字段含义。旧快照没有证明时保持原守卫，不从最新目录补入证明或新规则。R1两位角色revision从4变5，R2凯亚从5变6并保留E证明原语义；新配装、账号／项目、定义导出及Worker均保留完整字段。

计算器“检查当前内容”制备角色、武器、套装、主词条表与反应规则的更新副本，列出变化类别，经明确采用才替换该试配队员并重算。培养、实物数值及装备选择保留，不回写账号或原轴；自定义角色拒绝替换，比较基准存在时须先结束对照。旧效果引用与修订继续按原身份校验，不自动换绑。打开／读取／取消审阅都不执行更新，不恢复旧文件迁移。

自定义定义仍须显式校验同一契约，不因derivedFrom获得内置证明；从角色复制为自定义时清除damageCoverage，现有倍率编辑器修改参数也清除证明。直接编写JSON时，证明和revision是作者的来源审阅声明，不能当作服务器签名或防篡改凭据。未审更改须移除证明或重新审阅并更新revision，不得仅保留旧来源声称已核验。

8件基础武器逐件新增passive.kind=none及固定来源。省略passive不等于无被动，普通生成不推断或补这个字段。无被动声明不能同时携带修饰或战斗规则。一／二星基础武器合法最高70级、突破4、精炼1；非法精炼在静态配装校验中拒绝。

## 同轴候选

engine公开compareTimelineLoadouts，web领域层及axis.worker均调用该入口。请求是原项目与独立的完整Build替换列表，支持替换本角色或队友；每份候选重新装配全部内容规则，重求属性、捕获、来源和伤害。不同角色、缺少队员、重复候选／替换拒绝，不调用账号store，不写原项目，不生成攻击序列。

返回原方案、逐候选求值结果、目标差值、逐命中差值，以及变化的Build字段、增删效果来源。未知侧的差值为null；结果均保留各自plan、reads、effectInstances和分项。旧instanceId修订和适用事实保持原引用，换装后失效仍待核对，不自动附着到新来源。

AxisRequest可选candidates，AxisResponse可选comparison；原单项目请求仍返回result。候选失败返回invalid和错误，任务编号保留。计算器取消上一任务并拒绝旧任务响应，编辑立即清除旧结果。

计算器文件为schemaVersion1、kind=damage-calculator，携带当前项目、可选比较基准、查看队员与命中；只接受当前版本、最大8MiB。比较锁定记录、条件、敌人、定义、初始区间、修订和目标，候选仅替换配装；存盘重开后仍重新求值，不采用保存的结果值。界面“结束对照”后才能改变轴和敌人条件。完整动作可执行性、攻速／能量与整轴游戏观测尚未由伤害比较证明。
