# 命中属性的来源捕获

2026-11-13。P5公共伤害链的已实施增量；[完整范围](../planning/p5-character-usability.md)仍未完成。捕获沿用现有属性依赖图和before/after阶段，不新增解释器、捕获结果缓存文件或自动命中序列。

## 定义与原始记录

正式命中可声明snapshot，包含sourceSkillId、明确的属性集合及固定来源；共同角色schema检查来源技能存在，属性不可重复。它只声明哪些属性需要按来源读取，不把整个角色或全部增益一律捕获。

damage.capture显式记录recordId和phase，phase为before/after，任一字段可明确未知。项目校验来源存在、属于同一队员及指定技能，且位于当前命中之前；同刻依赖必须有明确order，不能用ID排序补猜。引用当前命中的before阶段可以表示该点的捕获断言，不能反向使用自身after阶段。来源记录、内容快照和原始状态不被求值改写。

此关联是输入对捕获点的明确断言，不是引擎推导的施放时机。不会自动选最近一次施放、把施放开始等同捕获时刻，或从固定帧数生成事件。2026-11-14的R2增量允许独立kind=capture记录，必须指定同一队员快照的技能和合法整数毫秒时间，关联无公式、无效果的定义；不能携带damage，也不计入目标伤害、历史命中或动作触发。它表示已确认的取值锚点，不表示一次施放，不替代引擎缺失的机制，也不证明完整操作在游戏中可执行。

web领域命令addAttributeCapture在副本中完整校验后原子写入，采用dependency配置；来源归属、技能和先后规则沿用原契约。计算器可输入命中秒数、独立捕获秒数并按角色／技能／时刻选择来源，再明确before/after。来源与命中各自保存，候选重求属性，不保存固定结果；没有自动创建动作、推导延迟或复制命中。既有时间轴的新增控件仍待审阅。

## 共用求值与隔离

伤害基数、元素增伤和需要的暴击属性按声明分别选择当前或来源reader。来源查询使用被引用记录自己的时刻、阶段、状态区间和命中覆盖，不携带当前命中覆盖去改写过去。命中限定的属性效果仍按正在计算的攻击类型筛选，静态类别修饰使用来源面板；效果自身的source捕获或显式capture节点继续读取它自己的来源上下文。

当前和来源属性分别缓存，避免同名属性混用；只读取本次结果真正需要的项。缺来源、未知阶段或上下文缺失时所需属性为null，不回退到当前值。反应精通和专属反应加成始终走当前命中读取，敌人条件仍使用本次伤害条件，不把它们随攻击属性一起冻结。

公开evaluateDamage保持原有参数，并允许显式提供DamageCaptureContext（来源reader与来源静态面板）；没有项目/来源上下文的直接查询保持部分结果。项目及Worker自动从明确的引用建立该上下文，复用相同伤害公式。结果保留捕获来源、阶段、属性及依据；读取记录包含实际来源事件、时刻和依赖，候选每次重新求值。

同一属性中可捕获贡献与动态直接修饰的更细分离仍需随实际规则接入；当前未实现的装备、共鸣和被动不能因此声明支持。通用damageBonus保持当前上下文，不等于所有游戏中的「全伤害提高」都已正确分类或实现。

## 已采用的范围与证据

固定KQM提交7fb4e7d的[捕获与动态说明](https://library.keqingmains.com/combat-mechanics/snapshot-and-dynamic)、对应[琴](https://library.keqingmains.com/characters/anemo/jean)和[凯亚](https://library.keqingmains.com/characters/cryo/kaeya)条目作为依据。来源事实保存在tools/data/sources/kqm-tcl对应提交的hit-capture-facts.json；没有复制或执行上游实现，也未采用捕获延迟常数。

琴爆发初始伤害使用命中上下文，领域出入伤害声明来源捕获；凯亚爆发冰棱伤害声明来源捕获。琴仍为零命单次范围；R2核对凯亚全部被动及C1仅修饰普攻／重击，增加C0—C1冰棱的查询证明，C2及以上继续阻断。治疗和整角色命座没有因此完成。行秋剑雨各波次的生成捕获、香菱旋火轮的延迟捕获和其它角色捕获仍待逐项接入，不能按最近一次爆发施放补齐。

独立计算使用90级零命、T9、西风剑/黎明神剑及明确敌人条件。核对基础公式、缺件、错误归属/技能/时序、同刻前后、来源生命条件及当前覆盖隔离；真实公开展柜圣遗物另用于明确标识的理论配装，核对宗室捕获、换武器重算及反应精通的当前读取。宗室过期检查的单次查询在凯亚8秒持续范围内，不伪造延长爆发。

浏览器实际Worker、文件往返及独立候选使用相同契约和独立期望；计算器已核对独立来源、不生成动作和多余命中、换武器及重开。实际公开展柜宗室实物的明确理论配装证明独立捕获点不会触发四件效果，另有显式爆发动作时才触发。这些是公式/功能检查，没有玩家战斗或游戏伤害观测，也不构成全角色或完整队伍验收。
