# 正式内容规则与共用求值

2026-11-13。P5伤害基础的已实施范围；[四类命中反应](hit-reactions.md)复用本图；全角色、其它反应、完整人工修订及比较出口仍见[P5计划](../planning/p5-character-usability.md)。

## 契约与来源

角色本体、突破被动、命座、武器和套装件数效果均可携带combatRules。每条规则包含ID、修订、固定来源、节点和效果；节点与效果复用项目的表达式契约，不执行代码或从描述推断规则。内置与自定义使用同一校验。

内容规则不绑定项目队员或事件ID。自身属性由规则所有者读取，接收者为自身或全队；来源事件使用明确的动作/命中及技能选择器。节点引用、重复ID、循环、深度和角色技能参数引用在共同schema校验。尚不支持把项目history/capture节点中的具体事件ID直接写进正式规则；效果的source捕获沿现有语义消费关联触发事件。

表达式补齐减法、min/max、比较、分支选择、精炼参数、技能参数及战斗状态读取。不同单位相加或比较会报错；属性转换可先除以同单位的一个属性点，再乘目标属性单位的系数。条件分支只读取选中项，未知状态不按零处理。

2026-11-14增加[命中基础加值及来源适用事实](hit-base-bonuses.md)。baseDamageBonus使用伤害单位，原有覆盖组和来源属性读取共同处理装备/队友加值；requiresApplication要求明确的本次命中事实，不凭常驻规则默认冷却或次数可用。规则可显式声明未支持，选中该规则时固定值修订也不能解除限制。

## 每次求值的装配

从当前候选Build快照收集规则：角色本体、满足突破门槛的被动、已解锁命座、当前武器、满足实物件数的套装。套装仅随真实快照件数激活，不按套装名称或清单存在激活。规则与项目已有定义同时进入现有依赖图。

派生定义不写回账号、项目或原定义。效果身份包含所有者、来源类别与实体、内容/规则修订及触发事件，结果保留实体和规则关联；更换来源后不将旧修订附到相似效果。ID冲突报错。禁用、固定值和失效修订继续使用原有机制，完整五类修订仍未交付。

套装效果与角色、武器效果共用对象、覆盖组、add/replace/stack、捕获、循环和预算检查。常驻效果显式声明permanent，不因最后一个合法查询时刻处于3600000毫秒而过期；有触发的效果沿用左闭右开区间和事件前/后顺序。

## 动作、命中与未知

动作可带skillId，必须属于相应队员的角色快照；不依据定义名称猜技能。现有时间轴通过addSkillAction原子地写入明确技能动作，通过addSkillHit只写入选定的一次命中，两者均不生成额外伤害序列。

内容效果可按动作或命中的明确技能/类别触发。没有技能归属的动作只形成待确认触发实例；在它可能影响的区间和属性上报告未知，不直接当作爆发，也不默认当作未施放。旧记录保持缺件，不新增迁移或自动补写。已确认发生在查询之后的动作不影响此前输出。

单次命中的appliesTo可限定技能、命中类型、元素和攻击类别。只读取当前输出实际依赖的属性与条件：例如纳西妲的灭净三业专属暴击率不影响战技点按，非暴击伤害不读取暴击属性，那维莱特生命增伤未知不影响无关物理属性读取。

[命中属性捕获](hit-attribute-capture.md)也复用本图：按明确来源记录读取指定属性，使用来源状态并保留本次命中的类别筛选；效果自己的捕获继续使用其自身来源。缺引用不回退动态属性，候选变化后重新计算捕获值，反应精通仍为当前读取。

独立面板是无额外动作上下文的基础查询，不推断未记录施放或补造轴前效果。实际项目的记录完整性、轴前状态和更复杂触发事实仍需继续补齐；不能据基础查询或孤立规则通过声称已复现真实整队战斗。

## 面板、直接伤害和时间轴

静态阶段resolveStaticBuild只计算成长、装备及静态修饰。公开resolveBuild在有内容规则时通过现有图查询属性；公开evaluateDamage创建内部单点查询上下文，时间轴同样调用共同的伤害公式。内部查询不是生成玩家项目或战斗记录，不持久化，也不从最新目录替换快照。

攻击、生命、防御的动态百分比只按基础值加入增量，避免重复静态百分比；固定属性转换不会被百分比攻击再放大。直接伤害的缩放项使用实际读取值；面板查询缺条件时保留部分状态和诊断。调用方显式提供完整属性reader时，伤害公式消费该上下文，不再重复装配内容规则。

已审计的成长和技能来源数值未变。新规则的精炼系数、阈值和上限由对应来源审查及独立计算核验，原有167133项数值审计不能单独证明新规则正确。生成的combat-rules.json覆盖全部154角色/形态、256武器和63套装的显式规则绑定；空条目仍待实现，绑定数不作为阶段完成率。
