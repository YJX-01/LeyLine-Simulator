# 产品需求与边界

保留已认可的主题与账号、轴项目、内容定义库三个数据领域。产品服务于真实配装管理、伤害核验、同轴换装比较，以及后续明确库存和约束下的全队优化、概率分析与录像复盘。当前能力以[支持范围](../architecture/content-support.md)为准。

伤害可用目标覆盖正式目录的全部角色与形态、武器及套装，不能用少数角色或一支队伍替代。目录收录、参数绑定、局部分项和测试通过不代表完整机制可用；与伤害有关的被动、命座、装备及队友效果属于计算依赖。

用户将在可运行应用中录入配装，实际战斗和换装对照在伤害可用后提供。来源调查和独立公式核验可以先行，不等待或反复索要这些后置资料。圣遗物扩展保留五星并包含四星；三星及以下实物暂缓，低星武器不在暂缓范围。

人工记录动作、命中及必要外部事实；引擎在记录完整性和初始状态明确时推导可确定效果。不自动展开攻击序列，不把漏记当作未发生。反应类型、触发归属和必要条件明确标注，不自动推演附着历史。

候选换装固定原轴、独立重算，不回写账号或原方案。伤害变化与充能、攻速、持续时间等操作可执行性分别判断。来源、独立计算、真实资料检查和游戏观测按[证据规范](../standards/evidence.md)分别记录。

已交付界面和数据安全规则继续适用；新增交互按具体授权实施，不能由计划或数据扩展推导出界面改造授权。此前讨论全文保留在Git历史；旧阶段实施设计已撤回，新的实施方案尚未确定。
