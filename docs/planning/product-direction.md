# 产品方向

保留认可的主题与账号、轴项目、内容定义库三个数据领域。以真实角色、装备与用户资料进行配装管理、候选比较和时间轴分析；定义可以复制与导出，快照独立、未知条件可见、计算结果可解释。

2026-11-11，用户确认扩展后续规划：基础重构已完成逐项审核，U1已结束；下一阶段P5以当前正式目录的全部角色基本可用为出口，覆盖当前正式目录全部武器、套装的主要战斗效果，并完成基础同轴配装比较。一支真实队伍用于早期贯通，多支不同机制的真实队伍用于集成验证，均不能代替全角色覆盖。

产品围绕三个任务组织：复盘实际配装、动作和条件下的结果；比较换装或条件变化的原因；在明确库存、锁定项和目标下优化全队配装。三者共用定义、效果规则和求值路径。视频是可选的记录依据，优化器提供候选配置，轴项目不依赖视频才能使用。

P5之后依次推进全队库存优化、深入概率分析、视频与深入复盘及整体收口。必要概率机制若影响角色基础使用，在P5支持相应范围；完整概率分析后置。内容覆盖持续按角色和机制两条线维护，首批角色不构成永久范围上限。具体阶段、完成条件和扩展次序见[实施路线](implementation-roadmap.md)，P5范围见[全角色基础可用计划](p5-character-usability.md)。

结果解释、配装差异追踪、参数敏感性、轴模板与打法分支、受控自定义规则逐步进入相应增量。不引入第二套计算路径，不预先建设动态插件平台、完整自动战斗推演、多目标或动作自动识别。已完成的目录整理不重开，保留已认可的交互；新增界面及交互按现行界面规范先审阅具体方案，不恢复退休页面或旧模拟器。

当前行为见[用户指南](../guides/user-guide.md)，约束见[规范清单](../standards/README.md)，能力边界见[支持范围](../architecture/content-support.md)。历史提案只保存在[归档](../../archive/docs/README.md)。
