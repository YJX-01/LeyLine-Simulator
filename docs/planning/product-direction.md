# 产品方向

保留认可的主题与账号、轴项目、内容定义库三个数据领域。以真实角色、装备与用户资料进行配装管理、候选比较和时间轴分析；定义可以复制与导出，快照独立、未知条件可见、计算结果可解释。

当前产品先夯实数据、求值和仓库边界，再依[实施路线](implementation-roadmap.md)增加真实内容与全队优化，之后扩展概率、视频和深入分析。目录整理不改变已认可的交互，不恢复退休页面或旧模拟器。

当前行为见[用户指南](../guides/user-guide.md)，约束见[规范清单](../standards/README.md)，能力边界见[支持范围](../architecture/content-support.md)。历史提案只保存在[归档](../../archive/docs/README.md)。
