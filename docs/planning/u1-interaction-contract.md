## 当前障碍与改造

源码核查：默认进入带历史合成样本的轴；账号角色需下拉选择；库存为所有物品同时展开编辑器；队伍入口首先展示 P3 通用节点及合成建队；账号页顶部仍显示轴保存与伤害状态。以上是源码证据，尚不是实际点击/耗时测量。

账号页作为初始入口，角色与圣遗物独立导航。库存采用搜索、部位/属性/占用筛选、分页卡片、所选详情；选中后才提供编辑。导入使用独立对话框，先预览再确认。账号保存状态与轴保存状态分别显示。

队伍页先展示队员卡片与从账号选择入口，再编辑所选队员；通用节点、定义 ID 与兼容编辑进入高级工具。轴工作区固定队伍、工具栏、时间轴和选中检查位置，计算反馈与错误就近显示；窄屏转为单列，不隐藏必须操作。弹窗使用原生 dialog，支持 Escape、焦点约束和关闭后恢复焦点。

所有编辑继续使用原 domain/store/Worker。拖动一次产生一次编辑命令，撤销/重做沿用原实现；保存期间继续编辑、迟到结果隔离与恢复保护不变。替换前保留可恢复资料或显式提示。P6 搜索、取消、比较、采用仅确定未来位置，不生成假结果。
