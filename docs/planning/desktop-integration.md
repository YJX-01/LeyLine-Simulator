# 侧栏工作台正式整合

2026-11-06。用户已认可侧栏布局、原神配色和凯尔特装饰，并授权正式整合。本文统一记录当前入口、操作、验证与能力边界；产品目标见[产品方向](product-direction.md)，阶段状态见[实施路线](implementation-roadmap.md)。重复的讨论、预览和 D0 交付文档已合并删除，历史由 Git 保留。

## 打开及日常操作

Windows 双击 `artifacts/desktop/Start-LeyLine.cmd`；或按 `artifacts/desktop/latest.json` 打开实际 exe。应用直接进入新版时间轴，无需进入预览页、运行 Vite 或输入命令。图像、SVG 和程序资源全部本地打包。

- **项目**：载入四个普通伤害模板、新建空轴、打开和保存轴文件。空轴可保存；完整角色和表达式创建器尚未实现，可先用模板或导入已有 v1 项目。
- **队伍**：选择当前轴角色，编辑候选武器与规范化属性，调整已有区间效果的时间、常量和明确/未知条件。这里只修改项目快照，不回写账号实际装备。
- **时间轴**：添加和删除手工动作/伤害点；修改时间、同刻顺序、归属角色、定义和目标标记。刻度、记录数量与效果区间来自项目，不再固定为两次命中或八秒。
- **伤害分析**：读取同一结果，选择目标点、查看贡献并定位回记录。未知总值显示待确认，不按零计算。
- **内容定义库**：当前提供轴内定义快照的来源、伤害根节点和已有常量编辑；全局定义存储及完整创建能力仍待实现。
- **设置与帮助**：支持范围、素材版权和旧工具入口。公式验收工具保留在 `#annotation`，与主工作台编辑同一项目，切换不会出现两份独立计算输入。

网页使用同一界面和项目格式，文件打开/保存适配为浏览器文件选择与下载。`#axis` 是主入口，默认地址和旧 `#design` 均进入正式界面。CLI `evaluateWorkbench` 及本地求值工具保持原契约。

## 可视化正确性检查

在“项目”载入普通伤害模板后，依次检查下表。期望值由独立算例给出，界面实际结果来自内核；修改输入后不要将原模板参考值当作新输入的期望。

| 操作 | 应看到的结果 |
| --- | --- |
| 武器甲、攻击 1000、倍率 2 | 两点 2400/2000，全轴及目标 4400 |
| 换武器乙 | 总值 4000，原武器效果消失 |
| 换回 A，攻击改为 1100 | 两点 2640/2200，总值 4840 |
| 恢复攻击 1000，只选第二点为目标 | 目标 2000，全轴仍为 4400，完整记录保留 |
| 两点分别改为 0、5000 毫秒 | 2400/2000，效果区间左闭右开 |
| 给效果增加未填写触发条件 | 相关点与总值“待确认”，不能显示为零 |
| 将条件明确为不满足，再明确为满足 | 总值先为 4000，再回到 4400 |

选择第一点展开公式与来源，应能追溯伤害定义、武器效果及区间；第二点不读取已结束的效果。保存轴，改变攻击后重新打开保存文件，输入、目标、条件与结果应恢复；导入无效文件时当前轴不变。网页同样操作应得到一致结果。

## 文件与状态

`stores/axis-workspace.ts` 保存当前项目、求值结果、角色/记录选择和修改状态。桌面原生对话框与网页文件操作都通过同一导入校验进入：格式、版本或引用非法的文件不能覆盖当前项目，未知条件允许保存。保存取消或失败不清除未保存状态；在对话框等待期间继续编辑，只把实际写出的快照标为已保存，新修改仍为未保存。

当前未实现自动草稿恢复、完整撤销/重做或关闭前未保存确认。切页保留数据；载入模板、新建或打开另一个项目会替换当前轴，请先保存。计算暂为同步纯函数，小型轴已验证；Worker 取消与大项目编辑属于后续 P2。

## 结构与数学来源

正式组件为 `WorkspaceShell.vue`，替代原 `WorkspaceDesign.vue`。它与公式工具通过同一 Pinia store 调用 `@leyline/engine.evaluateWorkbench`；纯展示模块 `workbench-display.ts` 只格式化 AST，不承担第二套伤害计算。移除原型中固定的倍率、伤害点数量及效果数值说明，所有公式引用、来源和区间来自项目定义。没有恢复旧角色重构，也没有扩充 P3 快照/历史/概率语义。

压缩图像和原创结纹保留已认可的主题。图像由 Vite 输出为带哈希的独立 WebP，避免内联导致脚本增大，并允许按需缓存；静态验证服务器增加 `image/webp` MIME。仍按原构建预算检查三种工作台资源集合，不提高阈值。素材预算及版权见[来源记录](../references/ui-assets.md)。

侧栏参考社区莫娜固定提交 `beaced4d82619aa86920d0054ab6114b5fc5608f` 的功能分组、选中状态和页面状态保留，不复用其组件代码。主题使用深星空蓝、暖象牙/羊皮纸与古金细边，原创凯尔特结纹只放边框和留白。7 张本地 WebP 合计 23,318 B，较原图缩小 65.61%；两张原创 SVG 合计 1,064 B。不使用专有游戏字体、大幅背景或运行时外站图片；游戏图像权利归原权利方，参考仓库的代码许可不构成图像授权。

## 本地打包

桌面版本为 0.2.0。正常 `desktop:build` 将每次产物放入新的 `artifacts/desktop/releases/build-*` 目录，成功后更新 `latest.json` 和稳定启动文件。已经运行的旧版本不被删除、覆盖或强行关闭；测试与开发启动工具通过同一清单定位最新 exe。旧预览参数只作兼容，不是当前正式入口。

应用保持 contextIsolation、renderer sandbox 和禁止 Node 集成。没有向页面暴露通用文件系统或执行任意代码的能力。产物未签名、未部署、未推送，只在本地保存源码与可运行程序。`clean:outputs` 会移除 artifacts，包括这些构建；清理前请另存需要保留的候选。

## 尚未支持

本轮已将默认工作台和公式工具的导航、说明、预设名称、记录名称、属性、单位、状态及诊断标题改为中文，通过集中显示映射保留后续多语言替换边界。原始标识和诊断原文收进折叠技术详情，文件契约保持不变；用户自定义名称保留原文。P2 新增页面与错误流程继续以中文为验收要求，旧开发工具的内部界面不代表产品中文化已全部完成。

账号选择和资料持久化、角色账号接口、真实库存导入和装备转移仍未接入，正式界面禁用相应写入入口并说明边界；素材卡片不代表真实物品。武器/圣遗物自动面板解析、完整内容库创建、视频、快照、窗口累计、概率与优化搜索均未因 UI 整合而实现。旧自动模拟器中的内容支持不能直接算作新轴内核的支持。
