三项技能为琴战技、凯亚战技及行秋战技，命中分别为1、1、2段。单项被动为行秋已登记的水伤修饰；具体仍以正式定义和[支持范围](../architecture/content-support.md)为准，本次不重新宣称其游戏实测通过。

已标记支持的七把武器是无锋剑、银剑、黎明神剑、腐殖之剑、西风剑、祭礼剑和旅行剑。正式说明明确：西风剑产球/能量不模拟，祭礼剑冷却重置不模拟、额外战技须自行标注，旅行剑拾球治疗不模拟。因此P5必须重查这些旧标记与新范围的对应关系，尤其不能把旅行剑治疗计为完成。

参考实现还存在产品口径差异：GenshinTools的`character5Fontaine.ts`芙宁娜实现采用选项指定气氛值并有默认满层设定；`character5Liyue.ts`胡桃实现使用生命状态选项及属性转换；`character4Mondstadt.ts`诺艾尔实现包含防御转攻击和命座分支。可以借鉴参数与依赖组织，但本项目必须由明确状态/记录驱动，不能复制默认状态或把其静态组合当作真实时间轴。辅助输出也需独立盘点，不能从伤害公式注册推断治疗和护盾支持。

## 建议实施批次

以下实体用于机制审查和参数核对，不代表选定玩家队伍。角色和装备的完整范围始终是三张全量表。每批只能报告已完成的路径，不因某角色出现在批次中就提前标记其完整可用。

| 批次 | 先核对的实体/资料 | 公共能力与出口 |
| --- | --- | --- |
| 装备前置：实际星级与实物 | 正式套装的实际稀有度集合及对应强化、主副词条来源；已有授权原件 | 补齐非五星培养、手动录入和外部导入，保留来源身份及预览确认；按实际星级核验，缺少原件不伪造；全套装使用前完成 |
| 1：现有路径与事件契约 | 琴、凯亚、行秋已有战技；无锋剑、银剑、黎明神剑、腐殖之剑 | 保留已有独立基线；落实动作与命中分开、状态区间、条件覆盖、单位和引用，核对合法命座/等级，不扩大为自动打轴 |
| 2：辅助、多属性和队友作用 | 琴与芭芭拉治疗、诺艾尔护盾/转化、班尼特条件增益；旅行剑治疗规则 | 接通治疗/护盾输出及作用对象，攻击/生命/防御读取、触发条件、必要概率口径和命座差异；默认状态不补造 |
| 3：条件转化与装备规则 | 胡桃、护摩之杖及与其共用机制的盘点条目；全套装触发规则 | 捕获/动态转换、上限、阈值、精炼和件数、套装来源及五类人工修订；反应规则所需参数并行调查 |
| 4：反应、累计及复杂状态 | 芙宁娜、优菈，以及全目录反应/状态线索逐条确认后的实体 | 反应归属与独立伤害、计数冷却、累计、层数、时间边界及命座交互；从明确事件计算，不自动假定满层 |
| 5：按依赖持续覆盖剩余目录 | 全部尚未完成角色、武器、套装；旅行者/特殊形态及参考未映射项单列 | 依据实际语义审查划分进一步批次，不能把剩余实体视为一次简单复制或用关键词批量标记支持 |

反应与复杂状态不是等到第4批才开始调查；某一前批实体的基础路径依赖它时，先实现必要能力或保持该路径未完成，不能宣称完整角色完成。实际实体分批在逐规则审查后继续细化，不预设全部目录工期。

## 已确认补充范围与材料缺口

全套装目标与当前五星实物范围存在实质冲突。2026-11-11用户已确认在P5补齐非五星实物的培养、手动录入和外部导入支持。按正式来源确定各套装实际星级集合、强化上限及主副词条规则，具体实施要求见[P5计划](p5-character-usability.md)。范围已批准，来源与实际输入材料仍需逐项核验；尚未修改契约或页面，不能仅放宽rarity校验或套用五星数值。

当前已有真实458件库存及独立公开展柜记录，只能覆盖各自材料范围，不能为上述审查实体编造玩家配装或混合账号。缺少对应实际资料时可以先完成规则调查及独立计算设计，相应真实资料检查和观测仍待完成。

下一步逐条审查首批实体及低星实物数据边界：核对来源参数、规则语义、精炼/命座/件数条件、合法输入和独立预期。全目录枚举及参考定位已经完成，逐规则审查和全部机制验收仍是后续工作。

非五星工作包已完成一轮来源及消费者核对，见[稀有度扩展核对](../references/artifact-rarity-expansion.md)。完整rarityList表明实际范围涉及一至五星；原表中低星级也可能有超出合法强化范围的行，不能以行数决定上限。升级配置关联和完整词条池依据仍待补齐，尚未采用生产数据。
