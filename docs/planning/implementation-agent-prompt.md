## 必须实现的操作改造

1. 轴工作区围绕角色、时间轴和所选对象检查组织；顶部清楚显示项目、来源账号、保存及计算状态。常用编辑不需要在完整定义和实例长列表里找字段。
2. 从真实角色/技能进入建轴、添加动作/伤害、选择目标、修改配装、查看伤害及采用来源。主流程不要求节点ID、AST、JSON或CLI；原始技术工具保留高级入口。
3. 捕获/动态、效果禁用/修订和待确认来源使用业务语言与上下文表达，按选中记录解释；不能把P3通用节点编辑器作为默认工作台。
4. 账号角色和实物库存支持可理解的选择/筛选、占用查看、导入预览及转移确认，保持账号实际装备和轴候选各自保存。
5. 明确空状态与下一步，输入错误就近显示；保存成功/失败/取消、计算中/取消/失配、恢复等状态不会混淆。切页保留必要上下文，真实资料和旧文件不丢失。
