## 不可偏离的产品方向

- 用户记录动作和伤害点，系统推导效果并计算；不自动补充协同命中，不推断暴击、反应，不改写轴。
- 模板保留动作和伤害点结构，武器、圣遗物等可替换；换装可能改变 Buff 和图结构，必须重新求值或编译。
- 内置与用户自定义内容使用同一套定义和计算能力，允许虚构角色；不把五角色枚举做成新系统的准入条件。
- 默认最大化整条轴总伤害，可选部分伤害作为目标；目标筛选不删除队友、快照或累计依赖。搜索变量与目标范围分开。
- 技能和 Buff 的部分快照、动态属性、计数器、累计伤害与概率语义都是核心设计约束，不可用不可扩展的静态面板模型锁死后续实现。
- 未知条件不是 0 或 false。允许保存不完整项目；优化前需确认目标依赖。充能始终可选。
- 轴独立于视频；项目保存快照和规则版本。多目标、全自动战斗推演不属于常规目标，多打法版本派生为远期功能。

将结论写入 `docs/planning/` 中单独的实施记录或专项调查，说明证据、已验证项和未解决项；已有目标文档不要改成流水账。

### B. P1：无界面普通伤害纵向切片

按仓库现有四包依赖实现最少且实际使用的契约、定义注册、属性绑定、表达式编译/解释、求值及来源输出。建议使用 `schema/src/workbench/` 和 `engine/src/workbench/`，公开入口通过 `@leyline/*` 暴露。

交付一个稳定的公开入口和本地可复现调用方式：传入包含轴、自定义/预设定义、候选配装和目标的 JSON，返回逐点伤害、目标值、结构化公式或计划、来源与诊断。可以用已有测试工具或小型开发工具调用，不依赖浏览器、网络或旧 `simulateCombat`。

首个切片只实现所需常量、输入、算术、区间效果和明确条件。结构化表达式采用可穷尽节点与受控操作，外部数据从 `unknown` 校验进入。不使用 `eval`、`new Function`、任意用户代码或 `as unknown as` 逃避校验。

不要提前铺全部未来接口与空目录。快照/历史/概率本轮未实现的能力明确诊断，不以永久 stub 或角色特判假装完成。基本结果能序列化并按 v1 输入重新求值，不能只返回无法保存的闭包。

## 验收必须覆盖

普通伤害例独立预期：两次命中在2秒、6秒，攻击1000、倍率2；武器A提供 `[0,5)` 的20%伤害加成，总伤害4400；武器B无该加成，总伤害4000；A攻击改为1100时总伤害4840。只选第二次命中作为目标得到2000，轴的其他记录仍保留。

另需验证：

- 同样定义以预设或用户内容加载得到相同结果；增加一个合成角色/武器不修改编译器分支。
- 换武器移除或增加效果，不能沿用旧 Buff；输入未被求值过程原地修改。
- 区间边界、稳定顺序、重复运行和不同项目之间状态隔离。
- 未知条件与明确否定分开，错误及未知带可定位来源；不把部分结果标成完整总结果。
- 缺失引用、非法数值、单位错误和表达式循环有明确诊断；已知未选分支不因缺失输入误阻塞。
- 项目输入及公式/计划能序列化，重新读取后求值一致；不需要视频或线上接口。

预期数值由独立手算/参考记录提供，不能照抄待测函数实现验证自己。
