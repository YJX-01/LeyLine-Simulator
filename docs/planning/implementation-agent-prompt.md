## 当前交付：D0 桌面与网页共用的 P0/P1 验收工作台

使用 Electron 薄壳与现有 Vue 共用界面。桌面原生窗口加载本机构建产物；网页运行同一份界面，计算调用现有 `@leyline/engine.evaluateWorkbench`，项目校验使用 `@leyline/schema`。Electron 和文件系统能力留在平台适配，不进入共享计算包。

用户通过 UI 完成：

- 加载普通伤害合成样本。
- 编辑攻击、倍率、武器、效果加成与区间、伤害时间及目标。
- 明确设置条件为真、假或未知。
- 查看逐点值、总值、目标值、结构化公式/来源及可定位诊断。
- 保存项目、重开项目并复算；非法导入保留现有项目。
- 对照独立参考期望验收，界面区分预期与实际，不在 UI 重写伤害实现来“证明”内核。

要交付实际可双击打开的桌面入口及使用步骤。开发者可保留启动/打包命令，但不以“先运行 pnpm dev 再打开浏览器”作为桌面交付。明确当前产物是否为未签名开发版本，不自行发布、部署或 push。

保留 `tools/scripts/evaluate-workbench.mjs` 给 agent，使用与 UI 导出相同的 v1 JSON。同一项目在桌面、网页和 CLI 的计算结果一致。原自动模拟器保留独立入口，不将其现有页面误标为本次工作台。

## 语义与能力边界

沿用 `workbench-v1` 的稳定 ID、整数毫秒、`[start,end)`、稳定同刻顺序、有限数值、单位及来源版本。换装重新求值，不能沿用旧效果；轴不被自动改写。未知不等同 false 或零，部分结果不冒充完整总伤害；项目允许不完整保存。

当前普通例：2 秒和6秒两次命中，攻击1000、倍率2，A 的 `[0,5000)` 加成0.2；验收 A 总4400、B 总4000、A攻击1100总4840、仅选第二次目标2000且完整轴保留。边界 0ms 包含、5000ms 排除；未知效果使相关结果待确认，明确 false 后按无效果计算。

快照、历史累计和概率仍明确未支持；快照例6900/7020/6600、累计例150/180仅作后续样本。不得为演示创建虚假通过值或角色特判。本轮不扩充 P3，不宣称已经实现完整 P2 的自定义表达式编辑、撤销/重做或完整视频工作流；实际增加的 P2 子能力逐项列明。
