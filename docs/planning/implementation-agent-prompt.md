## 连续增量与独立期望

1. 独立线性解析期望：区分复盘事实和期望口径，保存随机事件的稳定身份、概率和明确独立/共享关系。只在可证明线性独立时合并，不能把同一次触发的多个引用重复当成独立事件。
2. 相关分支和有限状态：阈值、计数、捕获、累计保留所需联合分布，用小规模完整枚举作为独立参考。两次独立50%事件“至少一次触发”为0.75，不是平均计数1；另列同事件共享引用、相反分支、概率0/1、相关触发和计数阈值的独立算例。不得使用蒙特卡洛近似冒充严格完整结果。
3. 条件完整性与准入：缺失事实可保存、可做部分分析；检查目标依赖和候选专属触发条件。仅在部分武器候选上触发的未知条件也必须发现，不能静默排除候选并声称完整。准入检查与正式搜索分开，P4不提前实现P6库存优化。未启用充能不因此阻塞。

每个增量均需真实UI消费者、可保存输入、实际Worker与CLI复算。状态/节点/访问预算、概率归一及算术溢出明确诊断；不能因预算不足静默截断、近似或输出完整标志。每次运行状态独立。至少用独立输入验证真实角色走同一概率/属性路径，不把真实内容永久留在静态分支；不要求扩充全部角色命座。
