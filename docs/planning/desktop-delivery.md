# 桌面可操作验收交付

2026-11-06。本轮落实用户修订：桌面 UI 优先，网页共用，CLI 留给 agent。当前是 D0（P0/P1 可操作验收），不是完整 P2 或 P3。

## 用户打开方式

在资源管理器打开 `D:\fish\LeyLine-Simulator\artifacts\desktop\LeyLine-win32-x64`，双击 `LeyLine.exe`。这是本地未签名便携版本；保留同目录的 DLL、resources、locales 和许可文件，不能只移动 exe。无须运行命令、打开浏览器或启动后台服务。初始加载普通伤害合成样本，不要求账号或视频。

## 在界面验收

左侧样本按钮加载独立输入，显示手算参考；右侧的实际伤害来自真实内核。修改后参考区会明确提示“自定义编辑”，避免把旧参考值当作新输入期望。

| 操作 | 正确结果 |
| --- | --- |
| 初始武器 A、攻击 1000、倍率 2 | 两点 2400/2000，全轴及目标 4400 |
| 在“武器方案”选 B | 总值 4000，武器效果区域显示无区间效果 |
| 选回 A，将攻击改为 1100 | 两点 2640/2200，总值 4840 |
| 恢复攻击 1000，取消 hit-2 的目标勾选 | 目标 2000，全轴 4400，两条记录仍保留 |
| 重新勾选 hit-2，将两点时间改为 0、5000ms | 两点仍为 2400/2000，证明区间左闭右开 |
| 直接点左侧武器 A 重置；勾“此效果需要额外触发条件” | 首点及总值待确认，诊断 unknown，不显示为 0 |
| 将“条件 triggered”选“明确不满足” | 总值 4000、完整计算；改为“明确满足”回到 4400 |
| 点击右侧 hit-2，并展开来源轨迹 | 可见 ordinary-hit、weapon-a/opening-bonus 和来源路径；hit-6 不读取该效果 |
| 修改“常量 multiplier” | 倍率随之改变，结果重新计算；无需编辑 JSON |

时间轴支持添加动作/伤害点、修改时间/顺序/定义和删除。公式区支持已有定义的常量、根节点及来源编辑；当前没有完整图形化表达式创建器。原自动模拟器通过左下链接访问，与新工作台输入隔离。

## 保存、重新打开与平台一致性

点击顶部“保存项目”，在 Windows 文件对话框中选择路径。保存完整 v1 轴、定义、候选属性、目标及未知条件；再修改攻击并通过“打开项目”选回该文件，界面恢复并重新计算。文件格式错误、版本不匹配或引用非法时提示错误，当前项目保持不变；取消对话框不修改项目。当前没有自动草稿恢复或关闭前未保存提示，请显式保存。

网页默认入口是同一个界面，使用浏览器文件选择/下载代替桌面对话框。agent 保留 `node tools/scripts/evaluate-workbench.mjs <保存文件>` 入口，读取完全相同的 v1 项目。当前真实角色装备导入、视频、快照、历史累计、概率与优化均未因此实现；快照/累计的数字明确标为后续参考。

## 开发、结构与验证

`tools/desktop/main.mjs`、`preload.cjs` 负责原生窗口和两项文件操作；应用从本地 `leyline://app` 加载打包资源，renderer 不拥有 Node 或任意文件系统权限。启用 sandbox/contextIsolation，拒绝新窗口、远程导航、webview 及权限请求，桥接校验主窗口来源。安全设置依据 [Electron 官方安全指南](https://www.electronjs.org/docs/latest/tutorial/security)。

`AnnotationWorkbench.vue` 与 `domain/workbench-project.ts` 共用 `@leyline/engine`，不复制伤害计算。四个 workspace 未改变；Electron 及打包器作为根级工具依赖声明，锁文件一起更新。`desktop:build` 生成相对资源路径的 Vue 产物并打包为本机平台程序，不推送、不部署。

验证已通过：数据检查、fixture 检查、架构检查、类型检查、192 项单元测试、三浏览器 90 项 E2E、根路径/子路径 24 项生产测试、生产构建及构建预算。新 UI 共 5 个浏览器场景覆盖普通手算、端点、未知条件、文件往返与窄屏。桌面实际 Electron 窗口测试覆盖 4400/4000/4840/2000、原生文件桥读写、未知/false、隔离设置和本地资源；截图为 `artifacts/desktop-validation/desktop.png`，保存文件可供 CLI 再验算。

桌面自动测试仅替换原生对话框的路径选择返回值，仍通过真实 IPC 和文件系统完成保存重开。工具容器下 Firefox newPage 崩溃、Electron Windows AppContainer ACL 拒绝读产物，改为正常本地权限后全部通过，未关闭应用 renderer 沙箱。首次 ESM 顶层等待 ready 的启动死锁也已修正为 ready 回调。产物目录曾补沙箱读取权限，未修改仓库外的系统策略。

本轮没有新的计算机制或搜索算法，不重复运行旧模拟器性能基准。新页当前同步求值，适合验收小轴；大轴 Worker、取消、完整撤销/重做、任意公式编辑与关闭恢复继续留在 P2。Windows x64 为本轮实际打包验证平台；其他系统、安装包签名和自动更新未验收。
