## 逐步验收

1. 双击 `artifacts/desktop/Start-LeyLine.cmd`；网页运行 `pnpm dev`。在“项目”或“队伍”点击“载入属性捕获示例”，目标应为 **6900**。
2. 在“队伍”将当前轴角色选“辅助”，候选攻击力从1000改1200，目标 **7020**；撤销/重做在6900/7020间往返。恢复1000，在“编辑 P3 定义”选择辅助角色定义，将效果2读取方式改动态，目标 **6600**；改回来源动作前捕获回到6900。
3. “候选效果与来源修订”找到跨角色转换实例，禁用后目标6000；恢复后6900；数值修订400后7200。保存轴，刷新恢复或新建后重新打开，仍为7200。改变来源定义版本、删除来源动作或换武器后，旧修订显示待核对，不能附着到新来源。人工值和禁用独立保存，清除按钮恢复推导值。
4. 展开“属性读取与捕获轨迹”：辅助1秒攻击1500、转换20%=300，输出3秒捕获2300，7秒动态增伤50%；`2300×2×1.5=6900`。修改候选后从输入重算，没有沿用上次捕获值。
5. 载入历史结算示例，只选择结算目标仍得到 **150**，全轴1350。编辑命中一定义常量100改120，命中四200改240，结算 **180**。窗口`[1000,6000)`排除6秒普通900和结算自身。
6. 编辑结算定义，窗口终点改6001并勾选包含当前结算，出现循环诊断和待确认数值。撤销或重开保存文件恢复180；可编辑观察角色/定义、计数方式、初值/上限、重置记录及同刻顺序。
7. 从空轴添加琴及战技命中，默认1549.2330752985004；显式采用P3，在“创建自定义效果”选来源、接收全队、攻击固定增量100，得到1772.6130752985004。撤销/重做和保存重开仍使用同一Worker路径。跨角色转换可改用来源攻击20%，不会修改账号实际配装。
8. 通用定义编辑可新建attribute/capture/history与算术节点，选择伤害根；效果可关联动作、接收者、属性、组及叠层规则。轴内定义可收藏至独立定义库并保存重用。机器身份和依赖路径位于折叠技术详情。

## 限制

受控属性单位仍为attack/scalar/damage，当前真实公式注入公共attack与damageBonus，其他真实属性的复杂动态转换后续扩展。未知条件保持待确认；覆盖/叠层历史里未知旧触发可能影响淘汰，因此即使后来存在已知覆盖，也保守报告部分待确认。没有自动推演命中、反应、暴击、协同或切人。

历史窗口是保存的绝对毫秒区间，连续窗口可由独立节点/结算记录表达；观察事件当前限显式伤害记录。重置后恢复声明的初值。每次运行最多100000依赖/扫描访问、128递归层，schema另限10000轴记录和每定义1000节点；预算终止不近似求值。确定性内核以访问预算终止，不使用不稳定的wall-clock截断；新图性能基准另设运行时间与序列化体积门槛。
