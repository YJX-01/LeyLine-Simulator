# 角色与圣遗物页面改进计划

2026-11-06。范围仅为 U1 账号资料操作，不引入优化器、模拟战斗或新机制。

1. **数据与编辑边界**：所有主词条展示读取当前等级表；导入原值只留在来源中。详情默认只读，编辑使用副本，只有“应用修改”才写入账号；关闭、Escape 和取消都丢弃未应用的副本。
2. **手动录入**：角色页直接选择角色、兼容武器与培养参数，预览后确认；采用用户指定的满等级、满天赋默认值，不推断实际武器。圣遗物页直接录入部位、套装、等级与词条，按部位限制主词条，校验后预览入库。未确认输入不进入账号。
3. **角色浏览与换装**：左侧可检索角色列表，右侧固定详情；姓名保持浅底深字。概览只显示资料、武器、天赋与属性，计算支持范围独立说明。五个装备位分别进入对应部位的库存，选用前可比较当前装备，跨角色转移继续明确确认。
4. **库存查找与详情**：增加套装、副词条、当前穿戴者和等级筛选、排序及清除筛选；搜索默认不混入历史穿戴备注。顶底均可翻页，卡片紧凑；完整主副词条与来源可直接查看，再显式进入编辑。
5. **定点核查与交付**：使用原真实莫娜文件的 458 件物品与 55 个穿戴备注角色。以源文件中 +20 生之花的临时副本验证取消保留 +20、应用 +16 后显示表值 3967；不改变原件，不构造库存或伤害序列。检查手动录入、部位换装、搜索空状态和窄屏，做相关类型/构建与单条 UI 操作检查，更新独立桌面包。真实武器资料尚未提供，不把界面默认值当作扫描事实或完整整轴验收。

验收关注用户能否找到、看清、选择和修改资料，不以新增测试数量评价完成程度。账号文件备份继续统一在设置页。

## 2026-11-06：账号页细化与统一配色

账号名称、角色/库存计数和保存状态收进紧凑页头；恢复草稿的长说明默认折叠，错误仍直接显示。账号保存与切换继续放在设置。角色查询行右侧统一为“网络导入”（水）、“莫娜 JSON”（雷）、“手动添加”（风）；左侧提供搜索和筛选弹窗，支持元素、武器、培养完整度、本地配装完整度与排序，已选条件可单独移除。配装完整度只统计本地实物，不把公开展柜快照当背包。

七元素原色/浅色/深色组成 21 色，与中性色和账号/项目/内容背景语义统一使用，规范见[视觉设计语言](../design/visual-language.md)。设置中可展开色板、检查色值与对比度、选择元素预览；v1 等待实际体验反馈，尚未冻结，也未实现深色模式。

用户明确选择 UID 查询公开角色展柜（Enka），本轮作为 U1 输入交互的有限增量落实：查询、预览、选择后确认，保存来源与只读装备快照。快照不进入实物库存，不按词条猜测与莫娜装备是同一件。当前支持范围、缺失映射和部署条件见[Enka 导入说明](../references/enka-import.md)。这不表示 P5 全内容/导入阶段完成，不提前交付优化器或新增机制。
