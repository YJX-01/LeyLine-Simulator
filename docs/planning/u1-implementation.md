## 操作路径与改造

| 任务 | 当前路径和反馈 |
| --- | --- |
| 导入库存 | 圣遗物 → 导入莫娜圣遗物 → 选文件后自动预览 → 确认 → 浏览卡片；确认前不写库存 |
| 查看库存 | 名称/穿戴备注搜索、部位页签、主词条和本地占用筛选；每页 30 件，点选才展开编辑和来源 |
| 整理角色 | 角色 → 从穿戴备注整理角色 → 确认；显示角色卡片及原始装备，继续补全真实角色/武器 |
| 配装与转移 | 角色卡片 → 从库存选择；跨角色转移保留原确认。实际穿戴和轴试配分别保存 |
| 编队 | 队伍 → 从账号选择队员 → 查看/修改配装；最多四人，检查重复角色与实物占用 |
| 保存队伍 | 给当前队伍命名 → 保存为新队伍；重新打开应用仍可选择；新建轴前明确提示保存当前编辑 |
| 独立轴 | 已保存队伍 → 以此队伍新建轴；队伍快照复制，独立轴 ID，可在项目页命名并另存 |
| 粗记 | 时间轴 → 动作/伤害层 → 选队员与技能；播放标注时钟，按快捷键记录。时钟不生成游戏事件 |
| 细调 | 分角色动作/伤害轨、光标定位、缩放、拖动；默认 10ms 吸附，Alt 为 1ms，右侧编辑精确时间/同刻顺序 |
| 计算与来源 | 目标条件面板；伤害点右侧明确暴击/反应。未知保持待确认，显示乘区与来源，分析可回到记录 |
| 保存与恢复 | 顶部按账号/轴分别显示保存对象；账号新建/打开前保留可恢复副本；轴沿用撤销/重做、恢复与 Worker 隔离 |

快捷键：1–4 选角色，E/Q 记录战技/爆发，Enter 记录当前所选技能，空格播放/暂停标注时钟，方向键移动光标（Shift 为一秒）。输入框、弹窗、按钮原生 Enter/空格不被标注快捷键抢占。普攻可在技能面板选择后 Enter 记录，专用键位仍未冻结。动作与伤害分别录入，不自动补全部命中，不猜暴击或反应。

弹窗采用原生 dialog，Escape 关闭并返回触发控件；窄屏筛选和卡片重排。旧 P3 规则编辑、历史合成建队和兼容样本留在明确的高级/历史兼容入口。`/#compatibility` 专供历史流程回归；默认入口不以样本和节点编辑开始。

改造前障碍来自用户反馈和源码盘点：默认样本轴、整页展开的库存编辑器、先出现通用节点的编队页、账号页混入轴保存状态。没有记录改造前人工任务耗时或点击基线，不虚构前后耗时改善比例。改造后的自动化操作记录覆盖真实文件选择/预览/确认、筛选、来源、保存重开和窄屏；这不等价于人工体验评审。
