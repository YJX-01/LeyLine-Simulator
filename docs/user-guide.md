# 地脉模拟器使用指南

## 开始使用

源码运行：安装Node.js 22.12或更新版本及pnpm 11.3.0，执行 `pnpm install --frozen-lockfile`、`pnpm dev`，打开终端给出的本地地址。当前产品完全在浏览器和Web Worker运行，不需要Python。已有生产构建可用 `pnpm preview` 本地查看，不要直接双击index.html。

默认示例是行秋、阿贝多、琴、胡桃的两轮24秒循环。保持种子1运行，可检查已验收示例的总伤害389,207.91及0条拒绝指令。更换装备、种子或动作后，须重新检查能量和拒绝原因。

## 编辑与计算

1. 在“配队与装备”选择角色，调整等级、突破、命座、天赋、武器、圣遗物和初始生命/能量。武器按类型筛选，属性预览可展开来源。副词条百分比直接填写百分数，例如充能20表示20%。
2. 在“动作循环”配置目标、时长、种子和日志模式，添加换人/施放动作。时间以秒显示、毫秒保存；同刻按表格顺序执行，可上移/下移调整。排序只按时间稳定排序，不替你保证冷却或能量。
3. 运行后检查伤害贡献、累计伤害、能量变化及前台/增益时间线。事件日志支持角色/类型筛选；命中记录可展开伤害乘区，拒绝记录说明动作为何未执行。
4. 修改配置后旧结果标记为过期，重跑后才可固定为对比A/B。对比差值为B减A，同时检查目标、种子、时长和模式差异。对比只保留在当前会话，刷新会清空；可导出两套配置与结果备份。

摘要日志不记录逐事件数据，因此没有累计曲线/能量时间线。详细日志达到上限时会明确失败，不返回截断的“完整结果”；此时可缩短窗口、提高日志上限至20000，或改为摘要模式。

## 保存与迁移

草稿在有效编辑后约300ms保存到当前浏览器。方案管理支持保存、载入、复制、重命名、删除和JSON导入导出；最多50个方案、方案库最多1MB。切换设备、浏览器、网站域名或端口，不会自动带走这些本机数据。关闭隐私窗口或清理站点数据也可能清除方案，重要方案请导出JSON。

载入/导入会替换编辑区，请先保存需保留的配置。只接受TeamInput v1结构化配置，不接受Python指令、执行代码或未知未来版本。结果导出包含实际运行配置，不会混入后来编辑的草稿。

## 故障恢复

- 页面资源未能加载：恢复网络后使用“重新加载页面”。版本更新期间旧资源可能失效，重新加载读取新入口；托管方应保留上一版本资源以减少中断。
- 图表未加载：数值表与结果导出仍可用，恢复网络后重新加载页面。
- Worker异常或主动取消：修正配置/恢复网络后重新运行。编辑或新任务会终止旧任务，旧消息不能覆盖新结果。
- 存储被禁用或配额不足：仍可编辑、计算及JSON导出；不要把失败提示当作保存成功。
- 本地数据损坏：应用保留原始内容，避免自动覆盖。先在浏览器开发工具的Application/Storage中备份 `leyline.plans.v1` 和 `leyline.draft.v1` 原值，再单独修复或清除对应键并重新加载。不要清空整个站点或其他服务的数据来尝试恢复。

## 支持范围

首批角色为琴、行秋、胡桃、阿贝多、雷电将军，包含选定的8把武器和五星圣遗物套装效果。模拟采用仓库审计的数据快照，结果记录引擎、规则、数据版本和随机种子，不代表当前游戏所有版本与全部机制。

当前是固定单目标、近战范围，不模拟敌人攻击、位移、命中停顿、动作取消、多目标或草反应；击杀条件不会凭静态敌人生命比例自动触发。阿贝多Q须明确生灭之花命中数，六命结晶护盾条件须明确勾选。期望模式对伤害暴击/角色产球取期望，条件装备触发仍受种子影响。

已在本机Playwright的Chromium、Firefox、WebKit验证。WebKit测试引擎不能代替所有真实Safari/iOS设备，Windows窄屏验证也不能代替触屏真机测试。没有账号同步、离线安装或自动配装功能。
