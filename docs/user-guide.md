# 当前工作台使用指南

打开 `artifacts/desktop/Start-LeyLine.cmd`，或执行 `pnpm dev` 打开网页。桌面与网页共用当前界面；旧模拟器和开发工具页面已删除。

## 账号角色与圣遗物

角色页右上有网络导入（Enka UID 公开展柜）、莫娜 JSON、手动添加。Enka 先查询、预览、勾选再确认；只能读取公开展柜。莫娜库存导入不虚构角色武器或培养，穿戴备注可整理为待补全角色。

角色卡显示姓名/状态、角色与武器、双方等级及 A/E/Q 天赋。点击卡片打开详情，已有角色身份固定；点击头像定位培养输入，点击武器更换，数值直接编辑后保存或还原。面板可折叠，下方圣遗物从实际库存更换；跨角色转移需要确认。展柜快照独立于背包实物，切换本地配装才可配置库存。

圣遗物页可搜索、筛选并查看实物。图片右下角是强化等级，悬停查看名字/部位；主副词条按游戏精度显示，保存值不改变。副词条圆圈区分接口记录与合法档位推断，详见[显示与强化次数](references/artifact-presentation.md)。

账号保存、打开与切换放在设置。浏览器草稿只用于恢复，请另存文件备份；删除旧界面不会清除已有账号、轴文件或浏览器存储。

## 队伍与独立轴

先在队伍页从账号选择已有角色，核对实际配装并保存命名队伍；以保存队伍新建独立轴。轴内候选改动不回写账号穿戴。项目页可打开、命名和另存轴文件。

时间轴先用快捷键粗标，再拖动细调记录。点击记录后在检查面板修改时间、同刻顺序、目标归属及命中条件。没有游戏录像或观察材料时不能把手动输入称为实测。伤害分析显示当前支持范围内的结果，未知条件和未支持机制会保留提示。
