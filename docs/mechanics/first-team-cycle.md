# 首个真实四人循环验收

场景：fixtures/scenarios/first-team.json，由 `node scripts/create-team-example.mjs` 可重复生成；`pnpm fixture:check` 不修改文件，只检查一致性。预期与审计推导不从引擎输出自动生成。

角色为行秋、阿贝多、琴、胡桃，均90级六突破、零命、天赋8，使用实际武器和五星圣遗物。种子1、暴击期望模式，祭礼R5概率触发按种子抽样。本场景不保证其他种子也能执行相同的双E时序。

## 一轮24秒

| 相对时间ms | 操作 |
| --- | --- |
| 0 | 行秋Q；首轮已有80能量，第二轮检验上一轮实际回满 |
| 800 / 2200 | 行秋E / 祭礼重置后的第二次E |
| 3700 | 切阿贝多、E放花 |
| 4800 | 切琴、E |
| 6000 | 切胡桃、E |
| 6600起每1400 | 六次N1 |
| 7000起每1400 | 六次重击 |

连续运行两轮共48秒：36次成功施放、7次切人、0次拒绝，祭礼触发2次，行秋Q2次，第二次Q施放前实际能量80，最终行秋能量再次为80。不存在外部脚本回能或强制跳过冷却。

## 独立审计

`team-cycle.test.ts` 首先检查以上事件与能量约束，再逐条独立计算全部伤害。参考计算不调用待测伤害函数：分别核对角色基础攻击/防御、天赋倍率、元素与类型增伤、暴击期望、防御0.5、抗性0.9和反应倍率，并独立求和核对总伤害。阿贝多后台防御倍率使用E快照；胡桃血梅香在E结束、雨帘剑治疗前后的攻击与低生命状态动态变化。

胡桃初始生命0.6M，两次E各扣当前30%。行秋两轮雨帘剑分别在17200/41200ms到期，各回复0.18X；因此最终生命为0.294M+0.306X，其中M为胡桃最大生命，X为行秋最大生命。这个结果独立于待测生命函数计算。

初始配装属性另有等级90、圣遗物百分比单位、护摩条件转换等人工算例；角色与装备触发各有独立用例，不能仅靠这个综合场景认定所有技能已验证。

## 范围

敌人固定90级、10%抗性、单目标、始终处于近战与领域范围，无敌人攻击、位移、盾和击杀。循环未使用琴Q、阿贝多Q、胡桃Q，不代表这些技能未接入；它们在独立角色与命座用例中验收。此循环证明真实四人技能/配装/后台触发和能量闭环，不是配队推荐或最大DPS优化结果。
