# 首批装备效果

属性由 resolveLoadout 按等级、突破、精炼、主副词条汇总，contributions保留来源。动态效果由统一内核的内容钩子执行，不提前伪造固定面板。五星圣遗物限定0—20级，校验部位、主词条、重复副词条和数值范围；暂不验证每条副词条的完整强化随机过程。

| 武器 | 已支持效果 |
| --- | --- |
| 黎明神剑 | 当前生命严格>90%时的暴击，召唤物按其快照策略保存 |
| 西风剑 | 前台暴击后按精炼概率产3无色粒子，精炼冷却，旅行后结算 |
| 祭礼剑 | 前台战技命中按精炼概率重置E，独立精炼冷却，多段分别有触发机会 |
| 腐殖之剑 | 战技伤害及战技专属暴击率，不影响普攻 |
| 白缨枪 | 普攻伤害加成，不加成雷电爆发转换后的普攻伤害 |
| 试作星镰 | E后普攻/重击增伤、两层和12秒时限 |
| 护摩之杖 | 最大生命、生命转攻击、严格<50%生命的额外转攻击 |
| 薙草之稻光 | 充能转攻击及上限、Q后12秒充能，动态更新转换 |

西风/祭礼效果使用显式种子抽样。expected对伤害暴击取期望，但装备触发仍是一次可复现的概率分支；不把条件触发的结果称为所有随机分支的总体期望。失败释放不触发装备，后台不能触发这两把武器。
