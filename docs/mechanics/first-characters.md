# 首批五角色：team-repo-v1

统一入口为 simulateTeam，输入为真实角色等级/突破、天赋、命座与装备；编译到 simulateCombat，角色只提供类型化内容钩子。不会把JSON作为可执行程序。数值来自固定repo-content-v1，帧序列核对KQM角色页。无敌人位移、命中停顿、冲刺/跳跃取消与受击。PL/PH表示已知时刻的落地冲击，不推算空中轨迹。

## 动作和状态

- N自动推进连段，切人/其他动作/超过2秒间隔重置；N1…N6显式指定段数，多段分别结算。C为重击部分，不自动额外插入前置普攻。体力240，消耗后1.5秒开始按25/秒恢复；场景不包含跑步与冲刺消耗。
- 琴：普通/重击/落地、点按/长按E、Q初始与边界伤害、领域治疗、A1概率治疗和A4固定回能。C1长按加伤、C2拾取粒子攻速、C3/C5天赋、C4风减抗生效；C6记录防御状态，无敌人攻击故不结算受击。
- 行秋：纠正旧代码复制雷电逻辑的问题；E为两次独立水伤与5粒子，Q按普通攻击动作触发剑雨。C0交替2/3剑、C6为2/3/5且第三轮回3能量，波次快照、刀剑独立附着计数。近战雨帘剑每2.25秒接触挂水，持续刷新不重置接触周期；到期治疗。A4水伤、C1剑数、C2持续/减抗、C3/C5天赋、C4独立乘1.5。
- 胡桃：E消耗当前生命30%、按最大生命转攻击且最多基础攻击4倍；9秒火附魔，切人结束，A1队友暴击增益。A4低生命火伤；重击血梅香动态伤害、4秒跳、刷新不重置跳时；Q低生命倍率/单目标治疗、攻击面板快照。C1免费重击、C2血梅香固定生命倍率与Q挂标、C3/C5天赋、C6生命降至25%以下的暴击窗口。静态存活敌人不会触发C4击杀增益；输出明确说明这一范围。
- 阿贝多：E初始攻击倍率与后台防御倍率刹那之花、同槽替换、2秒触发冷却、概率产球、快照。Q初始与明确指定命中数的生灭之花；不默认7朵全命中。生灭之花使用E施放快照。A1低敌生命增伤、A4队伍精通、C1固定回能、C2四层追加防御倍率、C3/C5天赋、C4场内下落增伤、C6在显式拾取结晶护盾条件下增伤。没有银花/魔导秘仪扩展；队伍仅含一个对应角色，不激活相关双角色条件。
- 雷电将军：E后台协同0.9秒与概率产球、按队友能量上限增伤；其他角色Q和粒子积累愿力，上限60且保留小数。Q首刀与7秒梦想一心，动作仍触发行秋剑雨但伤害类型为爆发；最多5次固定回能，充能提高回能与雷伤。C1愿力倍率、C2无视防御、C3/C5天赋、C4结束队友攻击、C6最多5次队友Q减冷却。

## 明确的场景条件

固定单目标、所有角色处于有效距离，雨帘剑接触与领域效果认为覆盖该目标。enemy.hpRatio为固定条件，不伪造敌人总生命/击杀模型。阿贝多Q必须提供enemy.fatalBlossomHits，结晶拾取必须显式设置collectCrystallizeShards。防御型效果不能在没有受击模型时被宣传为完整生存模拟。

条件产球在random模式抽样，在其他模式使用期望数。胡桃按核对后的2/3粒子3:2权重为2.4，而不是旧实现2.5。装备概率触发另由种子决定，因此expected表示暴击伤害期望，不是所有概率分支的总体数学期望。

## 差异与证据

角色页链接集中在 content-audit.md。旧行秋E/Q/普攻模块中存在雷电将军复制代码，不能作为业务真值。旧ActionTime缺行秋帧数，现使用核对的命中帧/动作时长。旧独立琴验证入口保留，使用旧767ms命中；统一内容按核对的21帧命中、46帧动作锁，两者不得混为同一规则。

同一波剑雨的多剑视为同帧命中；不同剑是独立事件。长动画持续触发剑雨和命中停顿延长窗口仍需进一步覆盖，当前首发验收循环避免这类边界。未知技能与角色、错误武器/主词条、缺少必要目标条件都会明确失败。
