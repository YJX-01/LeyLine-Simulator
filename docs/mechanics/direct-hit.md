# 当前直接伤害计算

engine/attributes/build.ts接收完整Build快照。属性先按等级曲线及突破求角色基础白值，再加武器白值、圣遗物和已支持的静态修饰：

`攻击 = (角色基础攻击 × 等级曲线 + 突破攻击 + 武器基础攻击 × 武器曲线 + 武器突破攻击) × (1 + 攻击百分比) + 固定攻击`

已支持的直接命中按以下乘区计算：

`伤害 = 攻击 × 天赋参数 × (1 + 对应增伤) × 暴击乘区 × 防御乘区 × 抗性乘区`

天赋参数通过`talents.hits[hitIndex].parameter`查找同一技能的parameters，再读取天赋等级对应值。普通命中暴击乘区为1，暴击为`1 + 暴伤`，期望为`1 + clamp(暴击率,0,1) × 暴伤`；未知暴击或反应条件返回诊断。

`防御乘区 = (角色等级 + 100) / ((角色等级 + 100) + (敌人等级 + 100) × (1 - 减防) × (1 - 无视防御))`

抗性小于0时为`1 - 抗性/2`；0至0.75之间为`1 - 抗性`；不小于0.75时为`1/(1+4×抗性)`。当前直接命中只处理明确无反应；不自动推断反应、站场或触发条件。

当前已核验琴、凯亚、行秋的零命战技，共四段绑定；其余技能/角色、命座复杂机制与未支持装备效果保留参数和文本，返回明确缺口。属性依赖、效果实例、捕获及累计在统一时间轴求值图中运行；直接配置会拒绝超出其范围的语法。

历史独立公式回归仍可用于检验重构前后数值，但构造场景不是玩家观测或新机制验收证据。数值精度依据见[审计](../references/numeric-precision.md)。
