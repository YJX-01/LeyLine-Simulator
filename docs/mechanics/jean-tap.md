# 琴 · 点按风压剑（仓库数据配置）

此配置用于逐项迁移，不表示当前游戏规则已完成验证。角色和技能来自旧仓库，配装测试值为人工构造。首批只支持零命点按 E、天赋等级1—10；不支持普攻、重击、长按、爆发、命座、被动、产球、反应、击退和坠落伤害。

## 数据依据与冲突处理

- 倍率：`docs/constant/SkillConfig.json` 的 Jean.E[天赋等级][0]，原始浮点数保留，不使用展示文案的百分数反推精度。
- 6秒冷却：同表 Jean.E[等级][3]，与 `docs/characters/jean.json` 的技能冷却一致。
- 旧 `archive/python/src/data/characters/jean/jean_elemskill.py` 中 `elemskill_cd` 硬编码10秒，与两份数据不符；新配置明确选用数据表6秒，不追求复制这一旧行为。
- 施放到命中：旧代码使用 ActionTime.Jean.E[1] = 46帧 / 60。整数毫秒中四舍五入为767ms，存在约0.333ms离散误差。
- 冷却开始延迟：沿用旧代码 ActionTime.Jean.E[0] = 18帧 / 60 = 300ms，因此在t施放后t+6300ms可再次施放。不是简单的t+6000ms。
- 动作锁：沿用旧代码的动作时长46帧，当前简化为767ms。
- 仓库 reference.md 仅写了 GenshinData、KQM、NGA 等名称，没有具体快照或原始链接；外部来源版本尚未核实。

## 属性与结算

攻击力 = (手动输入角色基础攻击 + 武器基础攻击) × (1 + 攻击加成) + 固定攻击。输入值是测试面板，不根据角色等级自动计算基础攻击，也没有武器被动或圣遗物套装效果。

技能注册表显式绑定 jean.e.tap，不通过字符串执行代码。每次模拟独立记录动作锁和技能冷却。命令先判断动作锁，再判断冷却；被拒绝命令记入日志且不刷新状态。命中在独立事件中读取动态增益。敌人有效抗性由调用者提供，应对应风元素。

同刻优先级：增益到期-2、增益开始-1、命中0、施放命令1。命中不提前处理后续命令，不支持取消动作。超过模拟终点的命中不计伤害，但施放日志保留预计命中时间。

## 验收算例

jean-tap fixture 设攻击力1000、天赋1、无暴击/增益/敌人减免，每次点按伤害约2920。0ms和6300ms施放成功，767ms和7067ms命中；100ms因动作锁、1000ms和6299ms因冷却被拒绝。总伤害约5840，8秒窗口DPS约730。

预期值来自手工乘法，允许绝对误差0.001以容纳原始浮点倍率；不得自动以引擎输出覆盖预期值。
