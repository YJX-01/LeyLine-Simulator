# 当前界面规范：以用户调整过的页面为基准

2026-11-08。当前唯一规范；过往迭代以 Git 历史和 U1 实施记录为准。按用户提出的七元素“原色、变浅、变深”建立 **21 色核心色板**，搭配中性色、语义别名与统一控件。本方案已应用到当前界面，仍为等待实际体验反馈的 v1 草案；配色检查通过不等于 U1 体验验收通过。深色模式尚未实现。

## 基准与边界

金标准是用户逐轮调整的账号角色详情、圣遗物疏松/紧凑卡及圣遗物详情。新页面沿用它们的颜色、尺寸、对齐、图标和操作位置。账号、轴项目、内容库仍为三个独立数据域；视觉复用不改变数据归属。

## 颜色语义

- 保存、采用和主要确认：风深色；另存及次要操作：风浅底深字。
- 删除、清除、放弃修改、还原：火色；删除必须说明对象。还原为浅底，危险确认使用深底。
- 本地资料：水；展柜资料：雷。莫娜导入统一为水色，展柜导入统一为雷色；导入按钮内外颜色一致。
- 普通文字使用中性深色，次级信息使用 muted。元素原色用于边框和图形，不用于小字号正文。
- 三域画布使用中性画布与各域浅色的低比例混合；使用 CSS 变量，不新增接近的十六进制颜色。遮罩和阴影允许透明叠层。游戏美术保持原色。

## 字号、控件和角标：当前强制标准

本节是用户于 2026-11-08 确认的现行标准。正文、提示、说明、标签、状态、表格、图表刻度、卡片属性和词条数字均不得小于 14px；不得通过 transform 缩放来绕过。信息拥挤时调整换行、列数、宽度和间距，不缩小文字。

| 字号层级 | 字号／字重 | 用途／变量 |
| --- | --- | --- |
| 页面标题 | 24px／700 | --font-title |
| 弹窗标题 | 20px／700 | --font-dialog |
| 分节标题、编辑数值 | 16px／700 | --font-control |
| 正文、提示、标签、普通按钮 | 14px／常规或中等 | --font-body；也是普通文字下限 |

| 控件等级 | 外框高度 | 用途／变量 |
| --- | --- | --- |
| 大 | 40px | 输入、等级、加减框、精炼、常规动作；--control-height-lg |
| 中 | 32px | 保存／另存／还原、来源切换、紧凑工具栏、关闭、等级预设；--control-height-md |
| 小 | 24px | 展开箭头等短图标；--control-height-sm |

高度均指含边框的外框；相连选择栏 40px 时内部按钮可为 38px，32px 时内部可为 30px，这不是新增尺寸等级。普通动作默认大，中号工具栏同排同高。小号优先纯图标，不承载长文字。复选框本体及装饰图标不套用三档按钮高度。带图片的目录卡、角色卡、可拖动记录等内容型选择容器按内容排版，不限制成单行按钮。

培养控件宽 160px；圆角 7px。间距以 4、8、12、16、20、24px 为主。编辑页工具栏固定在顶部；确认框最大宽 420px，正文 16px，取消与确认在底部右侧。窄屏允许工具区换行，不裁切标题和数字。

中号独立双字短按钮（如选装页“卸下”）使用 `data-size="md" data-width="short"`：高32px、最小宽64px（`--control-width-short`）、16px粗体。32px来自用户确认的高度档；64px是实现中的短按钮最小宽度，非用户指定的通用宽度。对照EditorActions的32px高、左右10px内距和FilterActions的104×40px：前者属于成组工具栏，后者属于筛选页确认动作，均不能照搬其宽度。64px给两个16px汉字留下均衡横向空隙，沿8px网格取整；长文字按内容扩展，不固定裁切，不推广到全部按钮。

### 角标例外（不得用于正文或提示）

角标仅指附着于图片或图标上的等级、命座、精炼、套装件数、圣遗物强化等级以及天赋命座加成星号。以 CornerBadge 或 data-ui-badge 明确标记，12px 标准档、10px 微型档，加粗且不再随图片连续缩到 8/9px。

- 标准角标：12px，容器高 20px、最小宽 20px，左右 3px 内边距；三位等级数字由内容撑宽，禁止裁切。
- 48px 及以下图片内使用微型角标：10px，高 16px、最小宽 16px，左右 2px 内边距。
- 命座按钮上的角标、天赋加成星号使用微型档。命座数字使用CornerBadge transparent，透明底、继承命座亮暗文字色，仅保留数字；不改变角色／武器等其他角标的稀有度底色。只有一至三个短数字或单字记号，完整含义由所属对象和可访问名称提供。
- “本地／展柜”“首选／备选”、状态提示、强化次数、平均词条数都不是角标，仍至少 14px。强化次数和平均条数的方框是主要数据，不得借角标例外缩小。

图片身份、稀有度底色、等级和命座/精炼角标使用 GameIcon/CornerBadge。角色详情图 104×104，武器图 88×88，天赋图 36px，命座按钮 40px，窄屏可用 32px。未点亮命座变暗，不加锁。

## 卡片与来源

圣遗物疏松卡图片固定 112×112，佩戴者 20px 位于图内左下，增强等级在右下。无人佩戴不放大图片；词条名与数字间距 12px。库存按至少 14px 字号排版，疏松/紧凑最小列宽 280/184px，等分填充行宽；紧凑卡隐藏穿戴者与原值，以属性图标和平均词条数展示。角色装备区固定疏松，不影响库存偏好。

角色圣遗物摘要按 4 件、2＋2、散件展示花图和角标。角色卡配置完整显示绿色“就绪”，不完整显示红色“缺失”；展柜存在时显示紫色“展柜”，不加勾号，缺失不显示。状态区整体宽 88px，与左侧圣遗物图片左边缘和宽度对齐，内部留 4px 间隔，文字不得与角色名重叠。详情中的“本地”来源切换仍使用水色，不能将来源色与就绪状态混淆。不同配装仍属于同一角色；默认首选是账号实际采用配置。

有效词条位于圣遗物下方常驻展示，使用七个图文点选框。生命/攻击/防御各合并固定和比例；默认值来自已记录版本的 miao-plugin 元信息，用户覆盖按账号/角色保存。

## 编辑和验证

账号角色、圣遗物、轴内队员编辑均先使用草稿，再显式保存或还原；关闭和导航保护未保存修改。应用内退出确认固定提供“保存”（深绿）、“继续编辑”（浅绿）、“放弃修改”（红色），确认动作40px、16px粗体。保存后继续原来的关闭／返回／切换；校验或写入失败留在编辑页，展柜组合仍须明确确认入库。关闭确认框与Esc等同继续编辑。WorkbenchDialog在keydown拦截Esc，避免连续Esc触发浏览器不可取消关闭而绕过草稿保护；原生cancel只处理自身事件，不能吞掉文件选择器的cancel。浏览器刷新／关闭由原生提示负责，无法替换成应用内三按钮。账号保存改变账号，队伍保存只改变当前轴候选，不回写账号。普通项目文件和定义库保持其文件保存、恢复及撤销逻辑，不能把所有数据域合并成一种存储。

功能流程与体验验收分开。日常定点检查使用真实莫娜库存和已记录的 Enka 快照；跨页检查包括 40px 控件、文字未裁切、危险确认、草稿退出及 390px 窄屏。公开快照派生的轴格式检查材料须明确注明来源，不冒充玩家导出或本地实物库存。U1 未完成整体体验验收。

## 账号导航与汇总入口

账号资料区依次为“角色”“角色配置”“圣遗物”“圣遗物组合”，四个入口均属于账号域。

角色配置先通过复用角色页的弹窗选择角色，再纵向列出该角色的首选及备选配置。角色详情标题只显示居中角色名，右侧次级名称框按“35.4词条|套装名|武器名”显示，点击名称框打开同一套配置列表；显示培养、武器、五部位摘要、全部七类平均词条数，可展开装备明细。切换配置不自动采用，有未保存修改时先确认。首选仍是账号当前配置。

有效词条合并为一排带平均条数的粗体点选框，始终显示全部七类副词条平均条数，生命、攻击、防御分别合并固定与百分比；选中项沿用风色强调。计数随当前草稿变化。角色详情的装备卡整体可点击，弹出复用的圣遗物库选择替换并提供卸下；不再使用更换/卸下角按钮。装备网格按容器实际宽度换列。

圣遗物组合为账号内独立保存的记录，保存五部位实物引用、装备快照及有效属性；莫娜导入、穿戴备注整理和角色配置保存均不自动创建组合。支持独立新建，或从本地／展柜详情显式“保存组合”。列表使用共用工具栏、摘要、七类词条统计和自适应分页。


### 圣遗物卡图文对齐（2026-11-08）

疏松卡图片 112×112px，与主词条 24px 加四行副词条各 22px 同高；名称和值间距 12px，图片与文字间距 10px。元素伤害加成在卡片简写为“火伤”等，完整名称保留在辅助说明。两种密度的主属性图标均放图片左上角；主属性图标和等级角标同为 20×20px。佩戴者头像留在图片左下角。疏松卡三者背景均跟随圣遗物图片的稀有度底色，不增加白底；紧凑卡主属性与等级角标使用透明底。紧凑卡内部间距 8px，副词条行间距 6px；普通数字保持 14px 粗体，等级角标 12px。


### 角色详情标题、来源和收藏

标题角色名水平居中，并与同排 32px 操作垂直居中。右侧为收藏五角星和次级配置名框，框内显示平均有效词条数、套装、武器，用竖线分隔，承担配置选择入口。窄屏分行保留角色名居中和完整配置入口，不压缩字号。本地/展柜为一体式分段切换，外框 32px，内项 26px（两侧 2px 内距和 1px 边框）；只有当前来源显示水/雷色选中底面。

“设为首选”只属于共用角色配置列表，主页面和选择弹窗同步提供，并确认采用和实物转移；原首选保留为备选。角色详情不提供设首选星标。五角星用于角色收藏，未收藏/1/2/3 级循环切换；同账号同角色所有方案共用，按账号和角色隔离保存。角色列表提供收藏等级筛选及收藏等级降序排序，不改变角色配装数据。


### 弹窗尺寸与主页筛选（2026-11-08，现行）

弹窗最大外框宽度统一使用 design-language.css 的语义变量：确认 420px（--dialog-width-confirm），筛选/排序 560px（--dialog-width-filter），内容选择 920px（--dialog-width-content），角色编辑 1000px（--dialog-width-editor）。角色配置选择与更换圣遗物的选择弹窗均为内容档；真实浏览器检查二者等宽。窄屏均受视口约束，允许内容换行，不缩字号。

角色主页仅展示每位角色当前首选配置，移除“显示角色不同配装”开关；其他配置集中在角色配置页。角色收藏标独立放标题右侧，角色名不包含收藏文字并保持居中。筛选/排序均用筛选档，角色筛选仅保留元素、收藏、星级、武器类型，采用16px粗体小标题、14px粗体选项和40px图文点选框；移除培养资料/本地配装条件及旧筛选状态。

圣遗物主页桌面筛选区只保留两行：首行搜索、筛选/排序、导入和添加；次行图文部位选择、清除、结果计数和卡片密度。详细套装、装备占用、主/副词条、等级放筛选弹窗。生命/攻击/防御筛选各合并固定和百分比，避免同名选项重复。手机按可用宽度换行。

所有共用 GameIcon 角色元素角标添加对应元素色及浅色投影；角色和武器的右下等级角标背景继承对应星级底色，不用白底。副词条高亮仅限角色详情及该详情的圣遗物选择流程，由父组件显式传入有效属性，采用火深色文字，不加高亮底色；圣遗物主页、角色配置/组合页不高亮副词条，不从佩戴关系自动推断显示高亮。展柜默认不映射本地实物；明确选择入库后的精确匹配遵守 Enka 导入契约。


### 共用主页工具栏、排序与筛选动作（当前）

角色与圣遗物主页必须复用 LibraryToolbar 和 LibraryImportActions，首行左侧搜索/筛选/排序，右侧莫娜/展柜（如适用）及手动添加；导入不单列成第三行。第二行放元素或部位，圣遗物筛选结果和卡片密度靠右；总数在账号管理显示，页码在列表底部，不为重复计数挤出第三行。
