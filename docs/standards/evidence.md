# 资料、独立核验与观测规范

使用可追溯的真实角色、装备、机制和合法参数。不得伪造玩家导出、库存、配装、战斗记录、伤害序列或游戏观测，也不建立tests/fixtures及替代输入归档。测试直接读取获授权原件；原件缺失明确跳过，不能生成替代资料或计为通过。

## 证据层次

| 层次 | 用途和可得结论 |
| --- | --- |
| 来源调查 | 明确版本、路径、规则语义和许可；上游存在不等于本项目已支持 |
| 独立计算 | 按真实机制与合法计算设定推导期望；不能调用待测引擎生成真值，也不能冒充玩家原配装 |
| 真实资料功能检查 | 验证原件上的导入、编辑、文件、求值或比较，缺事实保留未知 |
| 游戏观测 | 依据对应配装、条件和可追溯录像／伤害画面作对照；没有材料不宣称实测 |

目录收录、支持标记、分项公式和测试数量不代表整角色或全目录完成。一支队伍的结果不外推其它机制；共享能力可复用核验，角色参数及绑定仍须分别确认。没有录像不阻止来源研究和独立计算，也不能用缺件声明解除未实现依赖。

## 每项检查的记录

记录来源和取得时间／固定版本、适用角色及配装、目标与时间条件、用途、独立期望和容差、实际验证范围及缺口。声称游戏对照时附对应观测；只有软件功能或格式检查时明确说明，不混同观测。

来源保留精度、单位、ID及有意义的数组顺序；新数据先制备候选、审阅后采用，普通生成离线。许可不明的社区实现可调查，不据此复制源码。多个站点相同数据可能来自同一原表，不能自动算独立证据。

## 原件与派生边界

原件留在获授权的忽略目录.references，不随测试或文档提交。静态游戏目录和自动化应用导出不是玩家资料。格式／错误边界可透明派生于实际原件，记录改了什么，不保存为替代玩家导出或用作战斗事实。

理论换装使用真实合法装备参数，明确不证明玩家持有。不合并无关公开和私有账号。实物比较保留原ID、词条和占用边界；穷举与性能检查使用真实可追溯输入，不伪造大库存或攻击序列。

缺少触发记录不能当作未发生。可确定效果的推导须有明确初始状态和相关记录完整性；人工事实、推导和修订分开，不能重复计入。独立公式设定不授权伪造Buff、任意倍率或完整外部reader来冒充正式求值路径。
