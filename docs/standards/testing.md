# 测试与验证约定

所有活跃测试、辅助代码与固定输入统一在tests。单测按unit/schema、game-data、engine、web镜像实现；跨模块或实际原始资料检查在integration；浏览器分development与production，桌面和性能各自独立。源码及tools不存功能测试或场景构造器。

修复行为时检查相应回归，机制期望独立计算；低影响文字和布局不新增镜像测试。日常选择改动所需的检查，不重复整套浏览器与桌面。最终冻结后串行检查当前网页、桌面及根/子路径产物，浏览器与桌面单worker；只关闭本次创建且可证明归属的进程。

固定输入必须说明用途。按2026-11-10用户决定，删除历史构造场景及其专用测试/辅助代码，不再保留归档副本。当前功能仍使用的真实录存继续保留；原始公开响应保持哈希，私有原件仍在忽略目录，缺失时明确跳过。不得补造玩家数据、伤害观测、录像或完整时间轴，详见[证据规范](evidence.md)。

`pnpm test`运行单元与TypeScript集成检查；`pnpm test:content`运行Node文件/内容检查。结构整理的验证包含`architecture:check`、`data:check`、`fixture:check`、`assets:check`、`typecheck`、相关行为测试、构建预算和当前真实资料路径。性能报告必须描述实际测量范围与材料缺口。

文件保存/撤销/取消等软件检查可使用当前空文档；涉及角色和库存时使用真实录存。非法字段及缺失身份等派生输入必须说明改动，不保存为玩家原件，也不据此声称完成战斗机制验收。
