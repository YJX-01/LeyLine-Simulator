# 文件与状态

账号拥有实物库存、培养、穿戴及公开展柜快照；轴项目拥有队员快照、条件、记录和目标；内容定义库拥有定义及编辑草稿。各领域独立保存，跨域操作通过明确命令传递快照。

## 文件与草稿

应用文件的版本与软件版本统一，浏览器按用途和软件版本定位存储键。输入通过当前契约和版本校验后载入。版本不匹配时拒绝载入并保留当前编辑，已有磁盘文件和浏览器记录继续存放在原位置。

编辑先形成草稿，再显式保存、还原或放弃。异步保存以实际写出的快照更新已保存状态；期间产生的新编辑继续保持待保存。替换资料先完成备份，读取或备份失败时保留原字节和草稿。当前账号草稿读取失败时，自动保存保持原缓存；显式打开、新建或恢复先备份原字节，备份成功后再替换。

培养与配装保存身份、成长和装备；战斗状态由项目的[区间与命中上下文](calculation.md#战斗状态)提供。目标假设、暴击及反应选择分别记录确认状态。

## 导入与共享引用

导入按查询或读取、预览、确认提交执行。预览绑定当前账号及内容快照，确认时复核变更；取消或冲突保留当前状态。

展柜导入默认采用导入并合并，另提供仅快照选择。内容匹配逐项核对套装、部位、稀有度、等级、主词条和值及有序副词条；匹配成功复用本地身份，否则创建新物品。核验过的强化记录优先于推定，内容匹配与游戏实例身份分别记录。

同一物品可供多个角色、配置和组合引用。选装、采用配置和应用组合更新目标角色的草稿，其他引用保持。合并展柜经确认后完整替换所选角色的部位引用，缺部位清空，旧库存及其他引用保留。仅快照和单件入库分别处理快照、库存。

不同账号保持来源隔离。独立组合由显式保存动作创建；删除库存将现有穿戴、配置和组合保留为脱库快照，清除实物身份并展示持有状态。再次采用通过明确入库或替换完成。

## 独立计算

独立计算设定、比较基准和候选均使用各自快照。读取账号资料后在计算副本补全培养，更新内容采用显式审阅。计算文件内，基准和候选分别保存培养、装备和条件，以完整身份引用同一张内容表。文件保留角色专属数值，本机提供标准成长曲线和通用算法。通过版本校验的文件打开后重新求值，采用新的公共规则可能改变结果。

格式字段见[文件契约](../src/schema/README.md#文件与存储契约)，外部适配见[导入协议](../src/web/README.md#外部导入协议)，具体交互见[交互契约](../src/web/README.md#已确认交互契约)。

伤害列表按显式保存的设定保留快照。同一命中更改增益或配装后可并存多份。打开条目从保存的输入重算，存储失败时保留编辑状态。独立文件导入与导出用于跨设备携带同一设定。
