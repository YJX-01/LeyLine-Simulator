# 计算模型

## 伤害计算

属性与伤害消费同一配装快照。角色基础值由等级曲线与突破计算，武器白值按自身培养计算；生命、防御采用对应基础值与加成，攻击白值包含武器基础攻击。

`攻击 = (角色基础攻击 × 等级曲线 + 突破攻击 + 武器基础攻击 × 武器曲线 + 武器突破攻击) × (1 + 攻击百分比) + 固定攻击`

技能基数由各缩放项相加，每项为“读取属性 × 等级参数 × 输入因子”。[命中输入](calculation.md#命中输入与附加缩放)控制附加缩放，[属性捕获](calculation.md#命中属性捕获)确定读取时点。

`伤害 = (技能基数 + 效果基础加值 + 反应附加基数) × (1 + 对应增伤) × 暴击乘区 × 防御乘区 × 抗性乘区 × 增幅反应乘数`

普通命中暴击乘区为一，暴击为 `1 + 暴伤`，期望为 `1 + clamp(暴击率, 0, 1) × 暴伤`。反应基数和乘数见[反应公式](calculation.md#单次命中的元素反应)，来源加值见[基础加值](calculation.md#附加基础伤害与适用事实)。

`防御乘区 = (角色等级 + 100) / ((角色等级 + 100) + (敌人等级 + 100) × (1 - 减防) × (1 - 无视防御))`

| 敌人抗性 R | 抗性乘区 |
| --- | --- |
| R < 0 | `1 - R / 2` |
| 0 ≤ R < 0.75 | `1 - R` |
| R ≥ 0.75 | `1 / (1 + 4 × R)` |

直接查询、时间轴与后台任务共用公式及属性读取。缺少必要条件时保留已知分项与诊断，结构或单位错误返回无效。数值遵循[精度规范](content.md)，具体计算范围按[查询支持](calculation.md#计算支持判定)确定。

## 内容规则与共同求值

角色、被动、命座、武器和套装效果以可序列化规则进入同一依赖图。规则携带稳定标识、修订、来源、模板选择、参数、效果及支持状态，内置与自定义共用校验。固定TypeScript模板实现通用运算和已命名乘区，JSON提供模板所需的数据。同步与Worker按技能、命中及输出的稳定身份调用同一求值入口。

规则通过所有者、接收者和明确技能或类别选择器表达关系。具体项目事件在运行装配时关联；自身属性由来源所有者读取，条件分支按选中项取值。节点引用、单位、循环、深度和预算在共同契约与求值入口检查。

每次运行从当前配装快照收集本体、已解锁被动与命座、武器及实际件数对应的套装规则。派生实例保存在当前求值中，身份包含所有者、来源实体、内容与规则修订和触发记录。

效果复用覆盖组、替换、叠加、来源捕获与有效区间。常驻效果显式声明；触发效果按左闭右开区间和事件前后阶段读取。身份冲突和失效修订进入诊断。

动作与命中分别记录，技能归属由队员快照校验。触发归属待确认时，其相关区间和属性保持未知；结果按实际依赖读取属性与条件。

静态面板计算成长、装备和静态修饰；完整属性查询通过共同图读取内容规则。项目中的队员可只提供已知元素身份，缺失培养和装备时保留相关事实缺口。直接伤害和时间轴消费相同公式，调用者提供完整属性上下文时由该上下文承担装配。

动态百分比以基础值计算增量，固定属性转换按目标单位加入。禁用、固定值修订、规则支持及[命中适用事实](calculation.md#附加基础伤害与适用事实)分别校验。属性的来源读取见[捕获契约](calculation.md#命中属性捕获)，具体内容绑定见[资料入口](../tools/data/README.md)。

## 战斗状态

培养与配装表示成长和装备，战斗事实按队员与时间记录。状态区间及单次命中覆盖共同提供生命比例、站场和护盾存在状态。

区间使用整数毫秒和非空左闭右开范围。同一队员同一字段的区间互斥，不同字段可分别标注，相邻区间可共用端点。生命比例范围为零至一，布尔状态与明确未知各自保存。

字段读取按单次显式覆盖、对应时刻的区间、未知依次选择。省略字段继承区间，显式空值保留未知；零值、否定布尔值和未知分别处理。多位队员同时明确站场属于无效上下文，其他队员的省略状态继续未知。

每次求值重建索引与缓存，属性读取使用所读队员的状态。命中覆盖属于该命中上下文；动作与捕获来源使用自身时刻、阶段和状态，当前覆盖与来源上下文分别求值。

状态区间独立于事件前后阶段，同毫秒两阶段读取相同区间。区间表达人工标注事实。动作状态使用明确的初始值、动作及其他事件，在同一求值中生成各记录的前后阶段事实。状态规则的可执行性单独报告。

结果保留实际读取的对象、字段、时刻、记录、值和来源；覆盖值同时保留被覆盖区间的关联。编辑在副本完成校验后提交，删除队员同步清理其区间及其他命中的相关覆盖。

独立伤害查询使用自身条件，跨队员覆盖由项目上下文解析。字段定义与编辑入口见[契约入口](../src/schema/README.md)及[交互契约](../src/web/README.md#已确认交互契约)。

## 命中属性捕获

命中定义声明需要捕获的属性、来源技能和依据，项目记录明确关联来源与事件前后阶段。来源须属于同一队员及指定技能，并满足先后关系；同刻依赖由明确顺序确定。

独立取值记录提供来源技能和捕获时刻。施放动作、伤害与历史命中分别使用自己的记录类型。独立试算可以为命中选定默认来源与阶段，文件保存实际采用的关联。

当前属性与来源属性分别读取和缓存。来源上下文使用其记录的时刻、阶段、状态区间及命中覆盖；命中限定效果按正在计算的技能类别筛选，效果自身的来源捕获读取自身关联。

声明捕获的属性在来源或阶段缺失时保持未知。反应精通、反应专属加成和敌人条件使用当前命中上下文，基础加值按其来源规则读取。

直接查询可以提供明确来源属性上下文；项目与后台任务从记录关联构造相同上下文，复用共同伤害公式。每份候选重新计算来源值，结果保留实际读取记录和依据。

贡献级捕获与动态分类的进展随具体内容登记，相关支持及来源见[计算资料](../tools/data/README.md#计算支持与内容绑定)。

## 命中输入与附加缩放

技能声明有来源的输入标识、有限非负范围及整数要求，解锁条件可以修订上限。命中缩放项引用本技能的输入与等级参数。

层数、次数和累计点数可直接作为本击输入。独立计算器为缺失的技能计数填入声明的下限，保留已填写的零值。直接调用引擎时，缺失的必要输入仍按未知处理。未声明、越界、违反整数要求或非有限的输入会被拒绝。

技能基数为各项“属性 × 等级参数 × 输入值”之和，普通项的输入因子为一。已知零值贡献为零，该项专属属性按需跳过；未知输入使对应分项未知。

附加缩放进入技能基数，再参与增伤、暴击、防御、抗性和适用反应乘区。攻击次数、资源积攒、施放关联和可达性各自按对应事实表达。

直接查询、时间轴、文件和后台任务复用相同契约，结果保留各项参数、属性、倍率及输入。具体绑定、范围与来源见[计算资料](../tools/data/README.md#计算支持与内容绑定)。

## 附加基础伤害与适用事实

装备或队友提供的基础加值使用伤害单位，进入[共同伤害公式](calculation.md#伤害计算)的基础部分。技能基数、效果基础加值和反应附加基数分别保留来源与结果。

来源效果读取所有者属性，受益命中提供类别、元素和乘区。单位、覆盖组、循环、来源身份与预算复用共同依赖图；来源自身的捕获按其明确关联执行，受益技能捕获与基础加值分别读取。

需要次数或冷却事实的效果逐命中关联稳定来源实例，适用状态分为适用、排除和未知。排除时跳过该项专属属性，缺失事实保持未知。

关联须满足实际装配来源、接收者、命中类别及有效区间，触发先于命中，同刻依赖采用明确顺序。重复、错误对象、未来或过期关联进入诊断；来源变化后的原引用保留失效修订状态。

覆盖组先选择有效实例，再读取适用事实。禁用排除来源，固定值修订替代贡献，规则支持与适用事实继续分别校验。完整候选校验成功后提交编辑。

结果保留基础加值、来源依赖及原始技能缩放项。具体绑定和事实来源见[计算资料](../tools/data/README.md#计算支持与内容绑定)。

## 单次命中的元素反应

反应记录明确类型、触发归属和命中元素，明确无反应与未知分别保存。元素相容性在求值前校验，附着历史与后续独立事件按各自事实处理。

配装快照保存采用的反应参数、等级系数、修订与来源。既有配装沿用自身快照，所需规则或触发事实缺失时保留部分结果。

设精通为 EM，反应专属加成为 B，触发者等级系数为 L：

- 蒸发、融化乘数为 `C × (1 + 2.78 × EM / (1400 + EM) + B)`。水蒸发、火融化的 C 为 2，火蒸发、冰融化为 1.5。
- 超激化、蔓激化附加基数为 `C × L × (1 + 5 × EM / (1200 + EM) + B)`，C 分别为 1.15、1.25。
- 增幅乘数在最终乘区应用，激化附加量进入基础部分，反应专属加成使用独立无量纲属性。

反应精通和专属加成由当前命中动态读取。直接月伤按所选伤害族分别读取基础倍率、反应加成、暴击与对应元素抗性。聚合反应以明确的事件及贡献者求值，每个暴击状态分别计算、排序并加权。结果保留类型、精通、专属加成、系数、等级值、乘数或附加量以及规则来源；无反应与未知反应按自身依赖求值。

属性、技能基数及最终乘区复用[共同伤害公式](calculation.md#伤害计算)。具体来源、规则表和其他反应的接入状态见[计算资料](../tools/data/README.md#计算支持与内容绑定)。

## 查询覆盖与候选比较

查询覆盖记录实体修订、技能、命中、解锁范围及固定来源，并逐分支说明本体、被动和已解锁命座的相关性、显式输入或等级加成。

匹配查询须满足版本、命中及解锁范围，并完成全部相关分支审阅。配装、装备、来源规则和必要条件继续各自校验，队友属性使用队友自身的覆盖。缓存按具体查询区分。

覆盖随定义、配装、文件和后台任务保存。复制为自定义或修改倍率后清除原核验覆盖，派生关系保留来源关联。

### 内容更新

打开文件保留原快照。内容更新先制备定义与规则副本、列出差异，经明确采用后替换计算队员；培养和装备选择保留。自定义内容保持独立，比较基准在结束对照后再处理更新。

效果引用按原身份及修订校验。无被动声明须具备逐件来源，其定义同时满足相应结构约束。

### 同轴比较

比较固定记录、条件、敌人、状态、修订及目标，候选以同一队员身份替换完整配装。每份候选独立装配内容规则、属性、捕获和伤害，账号及原项目保持各自快照。

结果包含基准、候选、逐命中与目标差值、配装变化和来源增删；两侧数值均可得时计算差值，并显示各自的核验范围。任一侧缺少实际所需条件时，差值保持未知。来源变化后的事实及修订保留原关联，进入失效检查。

后台任务复用共同比较入口，携带会话、任务和修订身份。编辑清除旧结果，取消终止任务，迟到结果丢弃。重开文件重新求值，伤害比较与操作可执行性分别评估。文件字段见[文件契约](../src/schema/README.md#文件与存储契约)。

## 计算支持判定

内容收录、参数绑定、规则支持和查询覆盖分别维护。一次完整伤害需要配装合法、相关内容与装备规则受支持、查询分支覆盖完整、必要事实明确。

| 状态 | 含义 |
| --- | --- |
| 完整 | 当前查询的必要依赖及条件齐备 |
| 部分 | 已知分项保留，未知依赖或必要事实形成诊断 |
| 无效 | 结构、引用、单位、范围或版本违反契约 |

共享求值为每次命中提供伤害值、已知小计和覆盖诊断。独立计算器先用试算默认值补齐可编辑条件。仍缺少记录或机制依据时，结果说明具体缺口。时间轴按已记录的战斗条件求值。

角色、武器和套装的命中带有稳定标识，伤害族按本次条件选择。对于缺少公式的命中保留原引用和诊断。

支持按实体修订、技能、命中及解锁范围确定。角色本体、被动、命座、装备和队友来源分别校验。核验过的机制影响范围可以按受益者、实际属性和伤害族缩小覆盖缺口。未知影响保留为缺口。

共同求值能力包括结构化内容规则、战斗状态、明确命中的反应、属性捕获、命中输入、附加基础伤害和独立候选比较。界面输入覆盖、来源核验、软件检查和游戏观测分别记录状态。

具体支持清单、待接入机制及来源登记在[计算资料](../tools/data/README.md#计算支持与内容绑定)，逐项绑定可从正式定义及按需审计结果核对。产品目标见[产品方向](product-direction.md)，证据层次见[证据规范](evidence-and-validation.md#来源独立核验与观测)。
