期望由 `docs/planning/p0-samples.md` 的独立算式给出：捕获6900，辅助攻击改1200得7020，转换改动态得6600；历史150，前两命中改120/240得180。单测和浏览器、桌面使用这些期望，未从引擎生成真值。

`future-samples.json` 仍是非生产的早期能力参考，不将它改成可执行项目；其能力状态由阶段验收和新增生产样本记录。
