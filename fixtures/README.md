# 标准场景

buff-boundary 为人工构造的机制测试，不涉及任何角色或当前游戏数值。攻击力1000、倍率1、不暴击、无敌人减免。伤害加成0.5在[500ms,1000ms)生效，五次命中分别得到1000、1500、1500、1000、1000，总计6000。模拟窗口2秒，DPS为3000，包含截止时刻2000ms的命中。

expected 文件为以上人工算例的审核基线，不能由待测引擎输出自动覆盖。变更时间语义或公式时必须重新说明依据并审核预期。

jean-tap 场景使用仓库技能倍率与动作时长、手工配置面板，验证技能施放、拒绝原因、延迟命中和冷却边界。6秒冷却与旧 Python 10秒硬编码的差异、300ms冷却开始延迟和容差见 `docs/mechanics/jean-tap.md`。预期结果保持人工核算的十进制值。
