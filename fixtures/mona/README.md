# 莫娜第一版格式验证样本

这是依照固定上游类型与导出逻辑构造的最小格式样本，不是某位玩家的账号导出，也不宣称已取得扫描器样本。

来源：1803233552/genshin_artifact，提交 beaced4d82619aa86920d0054ab6114b5fc5608f：

- src/types/artifact.ts：IArtifact、词条和部位定义。
- src/pages/ArtifactsPage/ArtifactsPage.vue：getArtifactString 导出 version:'1' 与五部位列表。
- src/utils/checkImportJson.js：部位别名；src/utils/converter.ts 与 src/utils/utils.js：比例直接以小数保存，仅展示时乘100。

主词条使用仓库五星等级表的20级生命4780、水伤0.466。副词条保留原始小数，包括固定攻击的浮点表示。42与43是不同实物，属性相同也不能合并；44保留原始omit标记，导入仅增加库存，不推断角色装备。

第一版上游导出不包含装备角色。导入支持明确原始id；无id时用内容SHA-256与同内容出现次数区分同文件内实例，保证相同文件重复导入幂等，无法证明不同来源文件里无id的相同词条是否是同一实物。来源id内容变化列为冲突，默认不更新。同套装/部位的来源实物可明确勾选更新，保留名称与角色装备归属，预览后任何修改都会阻止覆盖。主值187的精通可按展示舍入导入，但计算继续使用canonical 186.5，原始187另存来源元数据。非五星在预览列为跳过，确认按钮明确导入五星数量。
